# V6.3.0 天穹試煉與星鑄強化

## 遊玩入口

蒼穹樞城新增「天穹試煉之門」與「星鑄師・赫瑟」。151以上地圖首領掉落的五種通行契各自開啟一條試煉，每次消耗1張、五位獨立首領逐隻出現。死亡或撤退立即結束，已掉落材料保留，不退券。人物戰敗後在村莊等待15秒，免費回城復活；不能在試煉內復活。切換瀏覽器分頁暫停，返回後繼續；重新整理或關閉遊戲結束本次挑戰，不補算離線試煉。

## 階段強化

每件角色裝備依「未強化 → D → C → B → A → S → SS → SSS」逐階進行；每步消耗1個對應星鑄結晶，100%成功，不能跳階。結晶在背包「階段強化」。強化綁定原裝備、卸下後保留，換裝不會繼承。換下的裝備退回背包，並提示新裝備需要各自強化；已強化裝備不自動分解，手動分解要確認且不退結晶。

強化提升原裝備已有的全部能力：ATK、MATK、HP、SP、DEF、MDEF、HIT、FLEE、STR／AGI／VIT／INT／DEX／LUK，以及暴擊、暴擊傷害、ASPD%、HP%、減傷等百分比詞條。沒有的詞條不會憑空增加。原始詞條不改寫，實際能力、裝備顯示與比較共用強化後數值。人物既有能力值預算、ASPD、暴擊率、最終減傷等上限照常生效。

## 外觀與第三大陸

全身最低階達到S、SS、SSS，各永久解鎖一套當前職業外觀；10個職業共30張獨立美術。混穿較高階不影響低階解鎖，例如9件S＋1件SS可解鎖S。選擇「角色 → 角色外觀」切換，不影響任何能力。後續換裝也不會失去外觀。

全身SSS首次達成後顯目提示開放「曙界新陸」，大陸下拉選單獨立列出。新主城「曙光聖港」，新區「黎明斷層」201～210；人物上限開放210、夥伴維持200。新區同樣依等級差給予出戰夥伴經驗，死亡時不獲得經驗；融合夥伴未滿200可繼續成長，滿級不累積EXP。裝備仍以200神話裝全身SSS、合法配點及卡片、融合夥伴配置為數值基準，尚不新增裝備或卡片。新區只掉各怪物獨有雜物：晨晶獵牙、曙岩角片、流光翼膜、黎明裁界晶（小怪1個、首領5個），在背包「曙界雜物」，可手動出售，永遠不加入自動販賣，全選也不會賣出。回城返回曙光聖港。

## 美術與驗證

使用內建image_gen逐張生成：25張試煉首領、30張職業階級外觀、4張曙界怪物／首領。圖檔放在assets/sky-trials與assets/rank-outfits；各自manifest保存完整提示詞、對應ID、透明圖檔與雜湊。

試煉測試使用實際戰鬥引擎，十職業×六種融合夥伴、固定seed731、頂級神話參考裝備與合法配點、卡片；比較前階與目標強化及部分70%配置。每場保留大量藥水、使用固定主攻優先技能順序，單隻首領最多420秒、曙界戰鬥240秒，不成長、不發放掉落。這是指定參考配置，並非所有技能排列或掛機經濟可持續性的保證。五連戰、死亡離場、掉落、存檔與抵抗另以執行期測試驗證。

數值原始樣本與摘要見sky-trials-v630.json及其壓縮原始樣本。舊地圖另以相同種子比對V6.1.2的900組未強化結果：擊殺、生存、尾王擊殺時間、主人／夥伴DPS、夥伴死亡、補給消耗與剩餘HP全部相同；原5100筆歷史樣本及雜湊保留。

本次保留2,940筆單王／曙界樣本、360筆實際五連戰及900筆舊地圖回歸，共4,200次參考戰鬥。191尾王單王：未強化0/60、S14/60、SS44/60、SSS60/60；完整191五連戰：SS41/60、SSS58/60，十個職業在每條試煉均有至少一種可通關夥伴搭配。初始70%參考配置通過各入口28、33、40、45、47/60；完整準備均60/60。曙界SSS配置一般遭遇60/60存活，首領與持續小怪60/60通過、平均約59秒。這些比例是固定seed731與參考技能配置的測試結果，不是遊戲內的保證勝率。
