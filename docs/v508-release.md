# V5.0.8 技能點、寵物等級與新區壓力

- 每升1級Job立即增加1點；Job2–50進一般技能池，轉生二轉Job51–70進轉生技能池。Job1初始技能1級視為起始點數。以已賺取點數減已投入等級重建帳目，讀檔、線上升級、多級跳升與離線模擬共用。截圖Job63、已投入7點的情況恢復6點；多次讀檔不會重複領。
- 二轉認證補齊一轉共50點的技能總額，因此Job40提早二轉的角色也能在轉生二轉Job70點滿全部一轉50級、二轉50級及轉生20級技能。保留已學技能與自訂自動技能順序；重訓退回各自點數池。轉生會清空前輪轉生點數。
- 技能選擇器保持焦點時，僅更新點數數字與升級按鈕的可用狀態；不重建下拉選單。手動升級立即更新畫面。
- 未完成99級界限進化／異化的寵物上限固定99，主人轉生不再解鎖寵物等級。舊版誤升的等級與EXP封存，付費完成界限進化後恢復，不刪寵物或裝備；封存期間高於寵物現等的裝備暫不生效。
- 修正讀檔仍可能卸下轉職後不符資格裝備的遺留邏輯；轉職、轉生及重新讀取都保留原穿戴裝與部位卡片。
- 101–110完全不改；111以上血量、傷害及命中依前階傳說裝80%設計基準調整。完整2120場測試與限制見[平衡報告](balance-v50.md)。
