## 解讀與仍待處理的配裝空間

1. 皇家守衛兩種承傷仍居這批候選首位；君王的 HP40／CLEAR43 在四種子先前已做額外複測。君王的輸出／清怪依然明顯領先大多數舊職業。
2. **第二輪證明第一輪表確實會低估角色**，尤其逐影物理承傷+16層、遊俠物理承傷+14層、大法師魔法承傷+11層；因此不可把第一輪或本輪的相對差距直接換算成技能傷害倍率。
3. **尚未交叉搜尋所有融合×所有七種配點**：第二輪只對各模式第一輪勝出的融合與特殊武器詞套用其餘五配點。未評估次佳融合與新配點組合的潛力。
4. **仍待比較**：所有合法武器型態、王卡替換與效益、技能施放優先順序、不同亂數種子。完成前不得稱作全局最優，也不得直接根據本表增減職業技能。
5. 這些是目前210等的測試，不是未來250等與本源覺醒四轉的平衡驗收；這部分玩法尚未加入此分支。
