# V6.3.2 天穹試煉連續挑戰

各角色、各試煉分別記錄完整通關次數。首次擊敗該試煉全部五位首領後，在蒼穹樞城的天穹試煉之門解鎖「連續挑戰」。單次挑戰入口保留。

連續模式每輪仍消耗1張對應入場券，不減免、不預扣全部券；五位首領全部擊敗後檢查下一張券與背包空間，才進入下一輪。不額外回滿HP／SP。戰敗立即回城並停止，不會透過自動復活繼續刷；手動離場、入場券不足及背包不足同樣停止，保留已取得結晶。

連續挑戰支援背景、不看戰鬥畫面、重新整理、關閉遊戲及返回選角。離線延用24小時上限，使用相同實際戰鬥、控制與原掉落規則補算，回來後自動結算；不以通關率估算或直接發獎。保存當前首領HP、戰鬥輪次、控制、技能冷卻、護盾與持續效果，接續未完成戰鬥，不重置首領或重複領獎。離線通關輪數及停止原因會顯示在結算視窗。一般單次模式仍維持原本離線中止的規則。

本版不調整怪物強度、裝備能力或掉落率。新增連續試煉測試，涵蓋各路線解鎖、逐輪扣券、死亡停止、實際離線通關與失敗、部分進度續戰、存檔還原及錯誤進度安全退出。
