# 君王／萬靈防禦能力重平衡（不修改怪物攻擊力）

分支：`feature/spirit-tamer-single-pet`。依照要求使萬靈物理／魔法生存壓力上限降低約 40%、君王物理降低約 20%，君王魔法不動。

## 實際變動

1. 君王完成能力加總後的 **DEF ×0.80**；MDEF、HP、減傷上限、ATK／MATK 不動。
2. 萬靈夥伴從主人繼承的生命上限比例 **45% → 16%**。
3. 萬靈夥伴防禦轉化：`DEF = 夥伴原始 DEF ×0.80 + 主人 DEF ×0.18`（原本為 `夥伴 DEF + 主人 DEF ×0.50`）；`MDEF = 夥伴原始 MDEF + 主人 MDEF ×0.32`（原本主人係數 0.50）。
4. **沒有對怪物 ATK／MATK 套用額外係數**；其他十職業不受修改影響。攻擊技能倍率、ASPD、卡片、減傷 40% 上限保持不變。涉及 DEF／MDEF 的防禦轉輸出機制可能因轉化下降而間接受影響，需作後續六融合輸出回歸。

## 相同條件壓力怪上限

- 210 等、契印 0、SSS、合法首領卡（排除 210 首領卡）、原 DPS 最佳候選配置、補血門檻 90%。
- 測試怪物物理 ATK 或魔法 MATK 單獨提高；保證每秒命中，傷害浮動取 85% 低端；其他參數沿用 `tests/spirit-single-pet-pressure-ceiling.mjs`。
- 數值為本輪搜尋中的最高「通過 N 下」區間，不代表實戰無限續航。
