# V6.1.0 融合戰契與三轉共鳴

六種融合寵物全部改為六招選三招，共36招。可在「寵物 → 當前出戰寵物」裝備、卸下，並用「提前／延後」決定自動施放優先順序；共用0.85秒施放間隔，各招仍有獨立冷卻及SP消耗。

融合寵的自身攻擊、群攻與持續傷害技能已重做倍率；雙方護盾仍有各自HP25%上限。裝備影響傷害、治療、護盾及增益；融合攻擊／魔法型可將裝備另一種攻擊數值的80%轉為主攻能力，使原裝備仍有用途。實際面板顯示每招倍率、額外目標、破防、回復及CD。

舊融合寵保留ID、裝備、等級、忠誠度及原有技能選擇，不會強制改配。舊存檔只有兩招時，頁面會提醒可以自行追加第三招。原本三個技能ID仍有效，新增的三個替代技能各有獨立ID。未融合寵仍為六選二。融合仍是寵物突破150、升至200的必要條件；經驗5倍／10倍規則沿用。

## 兩個人物階段，各自設計共鳴

- **進階二轉＋融合寵：60種。** 不需要先三轉。若尚未到JOB51、沒有轉生主攻，原本二轉主攻也可觸發融合戰契。
- **三轉＋融合寵：60種。** 完全獨立於舊一／二轉共鳴；主攻、範圍與終結技各有不同變化，部分搭配也可由三轉生存技或姿態開啟。
- **三轉＋未融合寵：** 使用三轉專屬戰契，依攻擊、魔法、防禦、輔助定位套用相應的新技能變化。

新共鳴持續8秒、冷卻4秒，觸發技能及實際效果會列在戰鬥共鳴與圖鑑。三轉共鳴倍率依目前Base顯示，程式以相同數值執行；不複製舊共鳴再附加品質加成。更換或收回寵物、調整技能、移動地圖時清除舊戰契。

## 傷害及貢獻

修正融合BUFF與烙印原本依賴主目標「受到主人攻擊後仍存活」才追加的問題。現在每次實際命中、範圍攻擊及最後一擊都在扣血前結算，以有效扣血量分攤主人與寵物來源，避免漏算、重複計分及過量傷害灌水。主人施放的寵物增傷仍歸主人。

新戰報使用版本61：傷害、有效治療、實際吸收護盾、實際承傷與有效防禦減傷均分開記錄。防禦減傷以受擊前HP＋護盾容量作上限；不計過量治療、未消耗護盾、假設攔截、重複受傷或SP。舊版戰報保留並標示，不混入新總貢獻比較。

配合融合寵強化，151–200一般怪物及獨立首領的HP基準同步調整；既有攻擊、經驗、掉落與入場券規則沿用。101–150數值沿用，另測進階二轉融合前後。
