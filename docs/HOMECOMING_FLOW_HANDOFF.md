# 十二種返鄉玩法｜接續開發
分支 feature/companion-homecoming，未修改 main 或部署正式網站。

## 已替換的設計
舊版統一「城鎮選答案 → 擊殺數 → 三事件 → 首領」已從測試頁移除。
dist/homecoming-adventures.js 是十二張獨立流程圖；每個節點可有資源條件、分支、局部重試或真正的戰鬥等待狀態。共用的是安全的保存與選擇驗證機制，任務不共用擊殺門檻或固定首領終點。
dist/homecoming-state.js 接入新流程，禁止用 investigate/field/node/boss 舊操作跳過新任務。recordHomecomingVictory 只在正確節點、正確地點、對應存活夥伴且在線上時接受戰鬥結果。
dist/homecoming-preview.html 提供各玩法的互動測試；戰鬥勝利仍明確標為模擬。

## 存檔與獎勵
- 首次來信、逐頁旅行、大陸解鎖、再訪直達城鎮維持原規則。
- 十二外觀各有獨立 adventure.step、vars、decisions。六種第四技能仍可由同系反向外觀其中一條完成解放。
- 任務途中每個選擇均可保存與重整；保存失敗回復操作前狀態。選錯不扣永久獎勵；沒有真實倒數或隨機失敗。
- 舊版 active 測試進度會從該路線新玩法的起點開始；舊 claimed 獎勵保留，不重發。
- 人物獎勵仍是十二條合計傷害 +3%、HP +4%、DEF/MDEF +4%、受到技能治療 +4%。目前只完成記帳，未接入戰鬥公式。
