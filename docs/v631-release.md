# V6.3.1 完整能力顯示與溢出潛能

保留既有裝備詞條、卡片能力與D～SSS強化倍率，不重骰、不降低裝備原有數值，也不改怪物數值。

裝備的六項能力各自以基本能力上限30%計算正常加成，卡片各自20%，沒有六項共用總額。Job加成獨立計算。基本上限99時，裝備每項29／卡片19；上限120時每項36／24；Base201起基本上限150，每項45／30。

人物能力維持完整的「基本值＋Job、裝備及卡片原始加成」顯示，例如150+70。詳細說明拆出正常加成與溢出。裝備及卡片的超額分別算出後，依同一能力合計轉為潛能，不重複堆疊轉換，也不把Job算進溢出。

潛能公式：效果比例 = 0.12 × 溢出點數 ÷（100＋溢出點數）。50、100、200點分別為4%、6%、8%，之後持續增長、邊際效益遞減，沒有到某一點就直接失效的硬切斷。

| 能力 | 溢出效果 |
|---|---|
| STR | 近距離物理傷害提高 |
| DEX | 遠距離物理傷害提高 |
| INT | 魔法傷害提高 |
| VIT | 最大HP提高 |
| AGI | 人物閃避率提高（百分點） |
| LUK | 暴擊傷害提高（百分點） |

超額不重複加入ATK／MATK、ASPD或詠唱的基本能力公式。INT、DEX完整加成雖然顯示，但詠唱仍使用正常生效的數值；溢出有自己的傷害收益。裝備與卡片的比較新增相應傷害、閃避加成差異。

Base201及以上的角色可在任一村莊「角色→人物能力」使用一次免費素質重置。金幣為0仍可使用，已配能力點完整退回，裝備、技能和未分配點數保留；機會隨角色存檔保存，之後回到原本金幣重置。沒有強制重置或自動消耗機會。

驗證集中在新增規則：獨立上限、遞減曲線、完整150+70顯示、各項實際作用、詠唱不重複加成、強化與比較不改寫裝備、201配點與免費重置保存／失敗回復。先前V6.1.2／V6.3.0戰鬥數據保留為歷史資料，沒有把舊的4200次測試冒稱為此版重新平衡。

本版新增13項機制測試；包含協同終極共鳴只增加人物傷害部分、反擊及實際受擊閃避，避免漏用或重複增加夥伴傷害。整體功能回歸共289項，另完成瀏覽器150+70顯示及零金幣免費重置驗證。
