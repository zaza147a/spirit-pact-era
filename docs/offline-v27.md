# V2.7 離線掛機

- 各角色透過 player.offline.at / enabled 保存最後進度與自動戰鬥狀態。舊存檔無此欄位時不追溯。
- 關頁、返回選角及切到背景時保存；背景暫停即時戰鬥，回前景或進入角色時補算，避免重複計時。
- 最多 24 小時，少於 10 秒不結算。未來時間戳、城鎮、死亡及手動暫停不提供收益。
- Web Worker 載入同一份 game.js。虛擬時間驅動 combatTick，使用既有敵人、技能、共鳴、補給、掉落、升級、自動購藥與分解規則，不以樣本收益乘時間。離線步進 200ms，與 20ms 即時戰鬥會有時序差異。
- 捕捉、進化、轉職、自動融合不執行。首領依既有設定避戰；未避戰可正常受傷、死亡、掉落，首領卡片仍為 0.1%。寵物之地無首領、無卡片。
- 人物死亡或背包達 1900 格停止，保留補算至停止點的成果。藥水用完不會憑空補給，只有既有自動購買設定可消費金幣。
- 全程在 Worker 的副本內計算，不寫 storage。完成後比對來源存檔字串，再驗證並一次寫入該角色。多分頁更新、運算錯誤或儲存失敗不覆蓋來源；刷新可重試，但未提交的收益不會重複疊加。
- timestamp 在提交後更新至目前時間，報告確認按鈕僅關閉視窗，不再次發放收益。報告列出淨金幣、總經驗、等級、消耗與購買的藥水、淨物品變化、新增裝備及卡片。
- 本功能沿用本機存檔與裝置時鐘，不提供伺服器驗證或跨裝置同步。

驗證包含實際 24 小時補算（48 小時離線僅計 24 小時）、死亡、容量停止、暫停／城鎮、經驗與掉落、藥水消耗、重複結算、角色隔離、存檔容量錯誤及併發變更。
