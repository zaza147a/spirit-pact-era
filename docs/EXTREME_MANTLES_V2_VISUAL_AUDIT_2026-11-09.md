## Alpha 正確合成後的重新驗收（2026-11-09）

- 逐組檢查 `docs/assets/extreme-mantles-ui-proof-{atk,matk,hp,clear}.jpg`，每組 12 職、各深淺背景；總計 **48 張視覺證明／96 個底色視圖**。這是按角色欄 CSS 圖框製作的合成代理圖，**不是瀏覽器實際截圖**。
- MATK 騎士的大片白塊示例：原始 WebP 的白色 RGB 像素 Alpha 為 0；正確合成至深底後，人物、武器及光效周圍無所謂「大片白底」。IS-Net 自動去背反而沒有必要。
- 唯一在此尺寸下明確看到矩形霧底的是 `clear-hunter.webp`。檢查發現矩形背景 Alpha 約 1–8；單張以 `scripts/art/trim-extreme-mantle-alpha.py` 將 **Alpha 1–20 歸零**，保留所有原本 Alpha >20 的 RGBA 解碼值，消除可見矩形霧底。此判定不適用於其他 47 張，避免誤刪薄紗／髮絲／光效。
- 試驗了 `rembg` IS-Net 與 BiRefNet-general-lite。前者對原始檢視器顯示的隱藏 RGB 幾乎無作用；後者能產出遮罩，但無必要改動已正常合成的圖。大型 BiRefNet 因記憶體限制退出（137）。**沒有批次套用模型，沒有重繪。**
- 尚待真人瀏覽器登入、角色欄切換及選角頁面逐張截圖；不能將本次合成代理圖稱為實際操作通過。

4. 此批**未改圖片、遊戲功能、角色／融合寵平衡或獎勵**；僅補齊人工查驗紀錄。維持測試分支；不合併 main、不更新正式網站。
