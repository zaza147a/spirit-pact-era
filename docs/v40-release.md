# V4.0 靈契轉生與村莊整備

正式發布僅使用 GitHub Pages。更新後重新整理仍先進四角色選擇畫面，各角色獨立存檔；既有寵物、裝備與神話寵保留。

## 導覽與操作

主功能收斂為角色、寵物、背包、裝備工坊、掛機設定、圖鑑。角色內分人物能力／裝備／技能；寵物內分管理／當前出戰寵物，出戰者的能力、裝備、技能集中於後者。卡片移到背包；職業與二轉介紹集中於圖鑑。商店、公會、二轉與進化均由村莊進入；移除獨立祭壇與貢獻報表分頁。下拉與輸入沿用穩定節點更新，避免戰鬥重建選項。

自動捕捉滿30隻時顯示常駐醒目提示，不使用捕獲慶祝框。管理支援選定品質以下批次放生，批次操作保護鎖定與出戰寵物。可進化時提示回村莊，野外不能進化。

## 雜物、區域任務與裝備門檻

99隻一般怪、10隻地圖首領與4類捕捉地寵物共113種獨立具名雜物，價值隨區域上升。直接金幣降低，掛機可勾選要自動出售的雜物。任務已接取時保留對應100個雜物，征途誓印不能出售。

51–99五區各有村莊任務：隨機指定當區一種真實怪物雜物100個＋當區「征途誓印」10枚。誓印由當區獨立地圖首領固定掉落1枚，卡片仍獨立0.1%；寵物之地沒有首領、沒有卡片掉落。不能藉重新接取重抽目標。

71／81／91區提供前一階罕見裝備約65%的整備提示，不強制封鎖地圖；特殊詞不列入估值。怪物攻擊的裝備階段增幅調整為1／2／4／8／14／20，HP、DEF與裝備核心階級曲線保留。裝備本身仍六階，不新增隱藏職業傷害係數。

## 一次轉生

完成五區任務、二轉Base99／Job50並回村莊可進行一次轉生。回到原系一轉Base1／Job1，屬性重置並獲20點自由能力；裝備、卡片、寵物、金幣與收藏保留，武器退回背包。1–99裝備等級需求忽略，職業需求仍有效。

轉生後角色上限120；Base100開始可將基本能力點到120，Job／裝備加成繼續列於＋值。1–99每級Base EXP需求是原曲線兩倍，100–120延續這條倍增曲線。此版尚無100以上地圖，可在既有地圖升級；沒有假設已存在新區域。

轉生二轉Job10／20自動取得本職業獨立BUFF／主攻，共20技能，不花技能點。付費重訓不退回這兩個免費技能的點數。技能顯示實際倍率、CD、AOE目標數與詠唱。新範圍主攻承接原職業共鳴，附加能力傷害係數50%、CD縮短最多20%，明列於說明；共鳴仍需真實命中／受擊／自詠等條件觸發。

新繪15幅透明職業美術覆蓋轉生五個一轉與十個二轉，選角、角色資料、職業圖鑑已接入。素材與生成記錄見 `reborn-art-v40.md`。

經驗差距採絕對等差：20級內完整，21–40級逐步下降，超過40級為0；人物Base／Job與寵物EXP各依自己的等級判定。掉落沒有等差懲罰。

## 驗證與已知平衡限制

裝備壓力測試共360場：10職業＋攻擊寵、三種子、71／81／91級、四種裝備完成度，對四個持續存活目標戰鬥45秒。70%完成度三區角色存活率皆100%；65%為71級90%、81／91級100%。攻擊寵在70%時平均倒下0.8／0／0.37次；滿額裝備則0.1／0／0次。補給足量、沒有復活，這是壓力測試而非所有配點都保證輕鬆的承諾。

經濟使用30場實際離線模擬（各60秒）：五區末等級、騎士／巫師／獵人、65%與完整罕見裝備。65%組雜物總售價49,061金、消耗藥水重置價44,340金，總覆蓋約111%；各職業仍有不同開銷，獵人部分配裝需直接金幣與掉落藥水補足。滿裝組覆蓋約246%，允許較有效率的農金；不能宣稱每個角色每分鐘正好收支相抵。選定雜物以外的裝備／卡片／誓印不會自動出售。

完整數據檔為 `balance-v40.json`、`gear-progression-v40.json`、`economy-v40.json`。


### 最終戰鬥重算

實際 combatTick 共1,440場：一般99與轉生120、40配對、野外／首領／四體三情境、罕見／神話、三個固定種子，每場120秒。人物與寵物使用同等級罕見裝備、IV3、不使用卡片或神話特殊詞。情境先正規化再等權平均；分數含實際傷害、有效治療、承傷防護與增益歸屬。固定合法配點與技能優先順序，並非窮舉所有配裝／玩家最佳化。
