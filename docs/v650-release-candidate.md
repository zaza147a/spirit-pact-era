# 靈契紀元 V6.5.0 發布候選

狀態：開發／驗收中。所有修改位於 `feature/humanoid-pet-evolution`，尚未合併main或正式發布。實體手機、Safari及原生鍵盤驗收依使用者本批指示跳過，不宣稱實機通過。

## 新功能

- 各村莊／主城新增「星橋保管員・米菈」。四個本機角色可透過200格共用倉庫傳送未穿戴的人物與夥伴裝備，原始UID、詞條及逐階強化完整保留。金幣、卡片及消耗品不入庫。
- 共用倉庫提供獨立匯出／匯入；單一角色備份不包含倉庫。相同瀏覽器重新匯入已轉交裝備的舊倉庫備份，不會增加第二件同UID裝備。這是本機四存檔共用，不是跨裝置雲端倉庫。
- 十職業S／SS／SSS共30套職業時裝重製，並有30個專屬名稱。S採精簡職業裝、SS改變服裝／護甲及武器結構、SSS形成職業終階輪廓；不是單純換色或增加發光。時裝仍只影響外觀，原解鎖及永久保留規則不變。
- 已完成的原始共鳴補正及既有成長／四角色／離線功能一併保留。

## 存檔與安全行為

倉庫以一筆本機裝備歸屬紀錄保存轉交，再同步角色資料。若中途關閉或角色存檔寫入失敗，裝備保留在倉庫或待送紀錄中；不以多筆非原子寫入嘗試回滾。背包已滿、倉庫已滿、角色倒地／野外／試煉內、穿戴中及非裝備物品都拒絕存取。

多分頁倉庫操作由Web Locks序列化。無安全鎖能力的連線不進行不安全轉移，提示使用HTTPS或localhost。其他角色存讀依共用歸屬排除已轉交裝備；離線結算若遇其他分頁變更倉庫，保留原存檔並重新結算。
