# 極限時裝人物比例與光環落點修正交接（2026-11-10）

## 截圖回報

- 刺客 ATK 突進立繪腳部高於畫布最下緣，既有光環固定在 V2 畫布近底部，因此視覺上光環落在雙腳下方的空中。
- 新版君王 MATK／CLEAR 以及刺客 MATK 的 1024×1536 畫布尺寸相同，但可見人物占比高於多數舊圖，因此遊戲內與選角頁看起來偏大。
- 前一版為了統一光環，連寵物金幣契印的偽元素高度與定位也改了；本批恢復寵物原始樣式。

## 本批修改

- 取消 `gold-collection-effects.css` 新增的地面投影覆寫區塊，讓寵物既有光環位置與尺寸恢復前版。寵物獨立顯示開關仍保留。
- 刺客 ATK 人物光環桌面定位 184px，行動版 160px；其餘 V2 仍維持既有底部腳下光環。
- 君王 MATK／CLEAR 角色欄顯示縮至 88%，刺客 MATK 縮至 92%，以圖片底部為縮放原點；登入選角頁也依比例略為縮小。圖片原始解析度及透明通道不變。
- 更新對應 CSS 的快取版本及測試。

## 驗收重點

1. 刺客 ATK 動態圖的光環是否正好落在兩隻腳的支撐面附近（不是透明畫布底部）。
2. 三張新立繪與舊角色在同一畫面比較時，人物尺寸是否合理；名稱框不能被腳或武器遮住。
3. 寵物光環關閉可消失、重新開啟可恢復原本效果，不能再改動金幣契印的尺寸與位置。
4. 正式版部署成功後需再以真實角色資料進行截圖驗收。
