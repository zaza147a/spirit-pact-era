## 極關鍵：Lv210 契印準備度

`dawnArchonPreparationFactor` 使對黎明裁界者的玩家、寵物與增益輸出按相同準備度縮放；未準備好不能只依全 SSS 宣稱首領必定可通關。

| 曙界契印階級 | 對首領的準備倍率 | 人物與寵物基礎面板 |
|---|---:|---|
| 0 | 34% | ×1.00 |
| I | 44% | ×1.02 |
| II | 54% | ×1.04 |
| III | 75% | ×1.06 |
| IV（只靠小怪材料可達） | 100% | ×1.08 |
| VIII（全階頂配） | 110% | ×1.16 |

應以 **IV 契印首次攻堅**和 **VIII 契印畢業頂配**分開記錄；兩者均使用同一套 210級SSS基礎比較條件，才能分離契印門檻效果。若主測為「最頂配」，使用VIII；首次突破另列IV。
