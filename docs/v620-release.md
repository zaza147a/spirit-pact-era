# V6.2.0 夥伴真形與羈絆

玩家介面全面統一稱為「夥伴」，包含主分頁、夥伴之地、出戰欄位、裝備、技能、共鳴、圖鑑、捕捉／放生、滿額與離線提示。英文字段及存檔ID保留，既有角色、物品、卡片、夥伴、暱稱及配置可繼續使用。

三轉需要及實際消耗天極覺醒聖印1枚，條件仍為Base150、轉生二轉Job70、蒼穹樞城，150首領掉落率5%不變。接取說明、道具說明、數量顯示與確認視窗統一。

## 隱藏真形

有效的融合夥伴達200級且忠誠度500，角色進入遊戲、分頁可見時才自動觸發。使用現有進化視窗，約4秒光影演出後揭露新名稱與人型外觀。六種配對、主副順序共12種造型；配對技能、技能配置、能力、共鳴、裝備、暱稱及等級上限均保留。進化不收費、不消耗素材或忠誠度。

提示：「恭喜！一路同行至今，你們早已親密無間。如今，牠終於願意卸下守護的外形，以原本的模樣與你相見。」

離線模擬與讀檔正規化只保留數值，不會設定真形旗標。離線結算中、獎勵視窗尚未關閉、背景分頁、角色死亡、其他互動視窗存在時，均延後演出。確認離線獎勵後才開始；中途切背景會取消本次演出並保留原形，回來並關閉新一次離線獎勵後重新播放。四秒完成且成功保存後才記錄已揭曉；之後讀檔不重複播放，多隻符合條件則依序揭曉。真形旗標保存在各角色存檔內。

## 忠誠度

既有每100次有效擊殺+1保留。擊敗首領額外有50%機率直接+1（隨機值小於0.5成功），若同時剛好達100次可合計+2，但最高500。只計出戰且存活的夥伴，怪物與夥伴等差不超過40；一般怪物不額外抽獎。相同award流程供即時與離線模擬使用，死亡怪物只結算一次，逃走或單純遭遇首領不給。

## 美術

內建image_gen製作透明背景12形態點陣圖集，保留龍、凰、泰坦、麟的融合元素，呈現成年、完整衣裝的人型守護者。生成提示及主副映射記錄於[art-manifest.json](../dist/assets/true-forms/art-manifest.json)。正式美術為[companions.svg](../dist/assets/true-forms/companions.svg)，內嵌生成後的透明WebP圖集，12個SVG view各對應一個主副組合；沒有以程式繪圖取代生成美術。直接用同一圖集的片段視圖呈現，保留透明度並共用快取。
