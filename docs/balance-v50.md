# V5.0.8 平衡驗證

本次使用實際 combatTick，每場120秒、20ms步進；三個種子42、137、731。共2120場：480場同階罕見裝備基準、1480場前階傳說裝備門檻測試、160場固定精英血量診斷。四格一般怪立即補位，排除遇怪等待、隨機首領、升級及掉裝成長，結果是持續戰鬥壓力測試，不等於實際掛機的每分鐘產出。藥水庫存刻意充足；存活不代表不用藥或收支平衡。

## 同階裝備的40種搭配

99級使用罕見寵物；150級使用已完成界限進化的傳說寵物，避免把無法合法超過99級的罕見寵物拿來測150級。人物與寵物均為當階罕見裝備。比較所有十職業×四寵物的三種子平均清怪速度，差距＝最快／最慢−1。角色技能使用當級可取得並已投入點數的完整技能；不是自動最佳化所有配點或優先順序。

## 111以上的60%／80%／100%門檻測試

111、121級使用91–110階段的Lv110頂級傳說裝；131、141級使用111–130階段的Lv130頂級傳說裝。人物十件、寵物三件均採合法五詞及各詞最大值；沒有神話特殊詞。寵物固定為已界限進化的傳說。配點遵守當級自由點總額及單項上限；卡片只能從前階地區取得，採各職業公開權重的攻守兼顧組合，未窮舉全域最佳配裝。

三組分別縮放裝備詞條、已配置屬性點、卡片效果至60%／80%／100%；Job加成、人物及寵物固有等級成長保留。這是可重現的投入比例比較，並非宣稱面板最終戰力剛好等於相同比例，也不是遊戲內新增戰力係數或入場鎖。卡片與能力值上限照實套用，因此效果不必然線性。

每組十職業×四寵物×三種子＝120場。以下「存活」指角色120秒內未倒下；寵物死亡會另記，藥水包含主人及寵物HP／SP。早死會縮短用藥時間，不能只拿總瓶數推斷哪組比較省。

所有111+的80%及100%配置均120／120場角色存活；較完整配置逐區提升清怪速度。60%在111、121區明顯不穩；131、141區仍可靠坦度與大量藥水存活，但效率低、耗藥高。80%是穩定攻略的設計基準，不是低於80%絕對無法擊殺。

這組「前階頂級傳說裝」不是上述「當階罕見裝」驗收。中途區域各職業清怪差距仍可能超過30%，且111／121的80%配置中攻擊寵仍可能多次倒下；沒有把它們藏進平均後宣稱所有地圖、配點與寵物技能選法都已符合30%。所有配對、寵物死亡、用藥及原始樣本均保留於JSON。

## 實際怪物調整

101–110的HP、ATK、DEF、EXP、命中、迴避與攻速不變，另有逐級測試鎖定。111–150怪物HP相對前版×1.8；111–130 ATK×1.6、131–150 ATK×1.3。命中111起1000，每級+20；131起2000，每級+20。首領沿用原有獨立倍率與命中+20。DEF、EXP、掉落率不變。調整的是怪物實際資料，沒有暗中削減玩家能力。
