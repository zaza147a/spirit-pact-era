# V2.4 戰鬥貢獻與平衡驗證

評分以實際戰鬥事件的 HP 等值為參考。傷害、有效治療、已吸收護盾、實際承傷及防禦減傷分別統計；BUFF 新增的傷害歸提供者。未消耗護盾、溢補、原始受傷欄位的副本及假設性的攔截估算，不再加入總分。SP 恢復與打斷次數分開顯示，不任意換成傷害。

一次命中的防禦減傷、護盾與實際 HP 損失，是同一攻擊的不同部分，分別計入一次。防禦減傷包含裝備及技能避免的傷害，讓提升 DEF 不會因實際扣血減少而失去貢獻。治療是之後補回缺失生命的另一個行動。此分數不是通用戰力：承受更高壓力可能累積更多保護分，因此必須同時檢查擊殺、生存與補給量，不能跨不同敵人直接比較原始分數。

## 實際玩法修正

- 命中率依 HIT/FLEE 數值的量級縮放，避免高階裝備讓敵方命中率長期卡在5%。HIT提高會增加命中，FLEE提高會降低命中。
- 防禦寵守護護盾優先分配給自己（70%），剩餘保護主人；兩者各有自身最大HP50%的容量。守護期間每秒依自身DEF18%有效自療，不增加直接攻擊傷害。
- 寵物治療共用原有治療預算，優先處理存活單位中生命比例較低的一方，未使用的部分可補另一方，不產生額外治療預算。
- 祭師聖域可優先治療受傷夥伴；自動施法會在需要時優先選治療。
- 寵物濺射不再重複套用人物提供的增傷。人物帶來的寵物增傷歸人物；寵物祝福及印記的實際額外傷害歸寵物。
- 自動終極共鳴依實際能量與30秒CD執行。守護與生命共振維持保護、治療定位。
- 高級紅／藍藥水在使用者Lv.51起，除固定量外回復最大HP15%／SP10%；Lv.1–50完全保留原固定恢復。寵物固定量75%，比例量依寵物自身上限。手動與自動共用同一公式。藥水恢復不歸角色技能貢獻。
- 二轉職業係數依完整輸出與支援玩法調整；十字軍盾擊來源為ATK65%＋DEF35%，避免DEF在坦度與傷害兩端都過度放大。

## 可重現的驗證範圍

執行 `node scripts/audit-balance-v24.mjs`。呼叫真實 `game.js` 戰鬥函式，每20ms推進模擬時鐘；自動補給每800ms以上檢查一次，回魔每4秒、技能CD、命中、站位、護盾、共鳴與終極共鳴均沿用遊戲邏輯。

720次＝10二轉職業×4寵物定位×2品質（罕見、神話）×3情境×3種子（42、137、2026）。每次120秒、Lv.99、同階罕見裝備、主屬性75%／耐久25%配點、個體值3、合法技能點上限、無卡片、每定位預設兩招寵物技能。自動補給開啟並提供充足藥水，因此另列實際用量，不代表每個組合都有相同成本。

真實遭遇情境採實際怪物HP、隨機遭遇與補位時序；測試固定等級、裝備與資源，不套用擊殺後升級及掉落。首領及四怪壓力情境採不能擊殺的測試目標，衡量持續輸出與保護，並非野外掛機的擊殺率。各情境先除以該情境40組的平均，再以相同權重綜合，避免壓力測試因承傷事件多而支配排名。

詳細結果見 `balance-v24.json`。報告包含實際傷害、寵物直接傷害、BUFF傷害、保護／治療貢獻、死亡、擊殺及藥水使用量。測試會校驗遊戲JS與基準腳本的SHA256，戰鬥來源變動後必須重跑。

這是固定配裝與預設技能的基準，不是所有配裝、卡片、技能二選組合及各成長等級的窮舉。各個單獨情境仍可超過30%，不同定位應有擅長的戰鬥需求。神話人物35–45%／寵物55–65%為整體基準平均目標，個別組合不會強制鎖定此比例。
