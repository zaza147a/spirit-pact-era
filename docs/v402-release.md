# V4.0.2 技能施放、傷害與任務怪修正

## 確認的原因與修正

- 人物護盾排在第一仍不放：自動邏輯要求HP先低於85%，將滿血或高續航配置的護盾全部略過。移除此HP門檻；目前護盾低於最大HP15%才嘗試補盾，仍遵守優先順序、SP、技能CD和25%共用護盾上限。護盾維持6.5秒，技能說明顯示可達上限。
- 寵物護盾／治療／增益不動作：原先只能在普攻之後、敵人仍活著時檢查技能。普攻一擊擊殺會把技能整次跳過。現在技能獨立於普攻排程，在普通攻擊前檢查；每招原有CD保留，兩招按裝備順序嘗試，共用0.85秒施放間隔。技能擊殺也會正確發獎。配置頁顯示冷卻、SP不足、滿資源、等待戰鬥等原因。全部卸下的配置在重新讀檔後也維持空白。
- 傷害看似相差十倍：原公式先把攻擊乘隨機數、再扣固定防禦，接近防禦門檻時可由1跳至數十。改為先扣防禦，再套90%–110%隨機浮動；暴擊依面板倍率乘在減傷後的傷害，避免防禦額外放大暴擊倍率。人物、寵物共用同一公式。尾刀紀錄分列命中傷害與有效扣血；暴擊與職業共鳴另標示，不把剩餘100HP顯示成一次完整100傷害。實際扣血與貢獻計分仍最多計入怪物剩餘HP。
- CD與ASPD混用：原本標為ASPD連發的11種技能（含轉生魔拳）不再把攻擊間隔當技能CD。獨立CD為0，ASPD限制與普通攻擊共用的動作間隔，最多每秒7次。施放仍由使用者的優先順序決定；一般有CD／有詠唱技能不會被誤改為自動額外攻擊。
- 本職業不適用裝備：工坊新增勾選項，優先分解有明確職業限制且當前職業不可用的裝備，不受稀有度保留規則覆蓋。等級不足不是職業不符。通用／寵物裝備仍走原有規則，換裝保護、融合目標和已穿戴裝備維持保護。掉落、手動整理、線上與離線共用同一判斷，預設關閉。
- 指定小怪雜物為0：掉落本來就是每隻專屬雜物必掉1個，但怪物池只挑玩家等級±2。99級玩家在91–99區域永遠遇不到任務指定的93級怪。移除此篩選，區域內全部怪物都可生成；不變更任務目標或既有進度。增加每隻雜物掉落紀錄與任務保留提示，已接取材料保留100個不自售。

## 技能驗證

新增實際遊戲執行測試：80種人物主動技能逐招經自動排程施放；30種被動逐招驗證加成；72種寵物技能（四系列×基礎／傳說／神話×六招）逐招驗證SP和實際效果。另測試一擊擊殺前補盾、冷卻／SP不足、空白配置讀檔、傷害邊界、尾刀紀錄，以及職業不符分解的新掉落與背包路徑。

任務測試遍歷99隻區域怪物的可生成性；在極高／極低RNG下重複擊殺93級目標，確認每次必掉並且自動出售仍保留任務材料。

戰鬥修正會改變實際輸出與防護，V4.0.1舊模擬保存在 `balance-v401.json`。新版完整1,440場重算將寫入 `balance-v402.json`，不沿用舊版平衡結論。

## 村莊任務 NPC

回城後點「征途引導官・艾琳」的「與艾琳對話 · 接取／回報任務」。二轉改由獨立公會轉職官處理。接取與回報都限制在村莊；新任務需達區域最低等級，依51–60 → 61–70 → 71–80 → 81–90 → 91–99順序開放。必須完成之前全部區域任務才能接下一區。既有已接取任務及材料保留，可繼續回村莊向艾琳回報。
