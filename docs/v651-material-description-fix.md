# V6.5.1 素材說明修正

使用者在正式版背包看到D／C／S階星鑄結晶說明為`undefined`。新增實際背包渲染回歸後先重現失敗：七階結晶與四種曙界素材的共用定義本有description，但game.js啟動時用缺少description的重複物件覆蓋ITEMS，連曙界素材map欄位也被移除。

移除11個重複定義，沿用sky-trials → loot → catalog的共用資料；獨立的裁界者核心註冊保留。物品數量、價格、掉落、強化消耗及能力公式沒有修改。背包恢復完整用途說明與既有曙界來源欄位。

驗證：新增實際game.js啟動／背包渲染測試，逐一核對7+4個說明、價格、來源欄位及背包數量不變。專項21/21通過。雙瀏覽器腳本新增桌面與390px窄幅的11個說明檢查及截圖，與原有存讀／進化／連戰回歸一同執行。

版本為V6.5.1。只有已修改的遊戲入口與離線worker改用6.5.1快取鍵；其餘未修改模組／圖片沿用原始版本。自動復活流程依使用者指示未修改。
