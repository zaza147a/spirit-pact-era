# 武器平衡第二輪：刺客與多等級傷害代理（2026-11-02）

本文件只供獨立平衡測試，主分支與正式遊戲未改動。

## 測試條件
以主武器攻擊詞條上下限中點，按照正式版物理傷害扣防禦公式和攻擊間隔公式計算。不同配裝使用同人物基礎攻擊、同敵人防禦。後期刺客三轉主攻倍率依正式版等級曲線與技能 rank10。未計入其他裝備、卡片、暴擊、共鳴、寵物、命中、技能排程及額外技能；**以下並非完整實戰 DPS**。Lv50／100／150 是固定倍率1的裝備代理，不代表真實技能倍率。

方案定義：
- 現況：副手攻擊100%，拳刃主攻0%加成，拳刃攻速比雙短劍少3（假設193對190）。
- A：副手35%，拳刃主攻+40%，攻速仍193對190。
- B：副手45%，拳刃主攻+50%，兩者都以193測試。
- C：副手50%，拳刃主攻+55%，攻速仍193對190。

## 判讀
在攻速193對190的邊界，+40%到55%拳刃攻擊仍無法補償攻速與副手差距。B接近，但只是後續完整引擎測試的候選起點，不是最終平衡結論。雙手攻速實際若到達193上限，應另行比較。

刺客技能檢查：雙刃亂舞、音速投擲已支援雙短劍及拳刃；拳刃旋斬仍僅拳刃，需在實驗版測試擴充相容性。三轉主攻沒有這兩者的武器限制。
