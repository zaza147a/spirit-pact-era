### 需要解釋的現象與限制

1. 萬靈的紙面 HP／DEF 都低於君王，受擊壓力測試卻能承受更高的怪物 ATK。代表不能用 DEF 一項直接推論存活率；後續應逐項拆解同化、協戰、護盾、卡片或被動的傷害處理與藥水使用。
2. 安全界線是在藥水庫存足夠、每秒強制命中、固定暴擊隨機取值的環境下取得，不等於自然地圖的無限掛機存活上限。
3. 君王、萬靈分別屬於自身配裝的「輸出候選最佳」，不是針對生存而另外最佳化 VIT、HP% 或減傷的版本。原十職比較須使用相同壓力測試及藥水數量才公平。
4. 程式在 JSON 外先建構測試怪；**不會把怪物加入存檔或遊戲**。角色的正式防禦公式保持不變。
