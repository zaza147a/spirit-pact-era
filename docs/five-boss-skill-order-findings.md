# 五王連戰：五組弱勢配法的技能順序回歸

基準為 Lv.200、裝備 Lv.190、未強化神話融合夥伴、單場最長 600 秒的合法五王連戰；本次重測先前 360 組中尚未通關的五組法師配法。每組測試三招所有六種先後順序，以及隨機種子 42、137、731，共 **90 場，22 勝**。明細見 `five-boss-skill-order-audit.json`。

| 主副系 | 所選技能編號 | 六種順序中的勝場（各 3 場） | 判讀 |
|---|---|---|---|
| 攻擊＋魔法 | 1、2、4 | 2、3、3、3、3、3 | 原順序有個別種子陣亡；其他五種順序全勝 |
| 防禦＋支援 | 1、2、4 | 1、1、1、1、0、0 | 順序影響有限，主要受傷害速度限制 |
| 防禦＋支援 | 1、2、5 | 0、0、0、0、0、0 | 不宜宣稱 600 秒內保證通關 |
| 防禦＋支援 | 1、4、5 | 0、0、0、0、0、0 | 無直接攻擊技能，屬純防護／回復定位 |
| 防禦＋支援 | 2、4、5 | 1、0、0、0、0、0 | 單一攻擊技加雙防護，輸出偏低 |

因此保留「六選三」與玩家自訂施放順序，不強制重配或以整體增傷掩蓋配法差異。技能設定介面對完全缺乏攻擊技能的融合配法增加提示。**其餘未通關案例仍列為已知配法取捨，不視為完成 360／360 通關保證。**
