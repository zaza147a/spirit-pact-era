以上是該原始檔觀測所得，**不是猜測，也不是最終最佳DPS**。首批數據中的角色裝備為固定神話中點詞條、主屬性與AGI/LUK/DEX優先，VIT常常只有1。生存失敗不應直接判定遊戲正式全部配置不可能通關。首批資料僅能證明該批配置無法穩定支撐連續刷怪及首領戰。

### 從實際程式查出的嚴重級差
`dist/combat-balance.js` 使用 `incomingMonsterDamage(atk,def)=atk*500/(500+def)`（另乘命中、抗性等），不是以百分比先行壓低數百萬的傷害。Lv210怪物原始 ATK 約370萬～416萬；首批測試角色最大HP約1.7萬（SSS後）。因此大量角色實際在1～5秒死亡。需優先測試VIT與合法高血量／減傷詞條是否足以生存，不可直接把短命戰鬥的高爆發DPS當成最優刷圖配置。

## 已修改的實測流程
- `tests/real-combat-browser-benchmark.mjs` 為每組職業×融合新增兩組合法配點：傷害優先、VIT生存優先。新的完整測試是 120級別/職業/融合組合，200級的60組×2，210級的60組×兩契印×2，**共360場真實混戰**。
- 目前每組優先武器只測一種，並未遍歷全武器、卡片、詞條、技能排序，所以新結果仍是**候選比較**，不是全裝備最優解。
- `tests/rank-natural-map-combat.mjs` 會由360場選出180筆對照，輸出最高觀察DPS、最久存活配置及另行的首領DPS，標記 `battleWindowCertified`、`bossBattleCertified`，避免將1–5秒死亡結果宣稱為完整首領DPS。
- 腳本在首領召喚前死亡，應記錄 `bossCallAttempted=false`、`bossEncounters=0`，不能算通關失敗，也不能捏造首領DPS。
- 對同一種子、同一場景保留人物／寵物／小怪／首領之逐次扣血歸屬以及藥水消耗。

## 後續接受標準
1. 取得360場原始Chromium實際戰鬥結果，且小怪／首領承傷、人寵歸屬完全對帳。
2. 若生存優先配置仍全滅，就在隔離分支上以原始基準做**成對AB實戰調整**，而不是先改正式版。評估191–210怪物攻擊、HP和高階人物防禦/HP倍率；保留原版結果以供比較。
3. 四欄持續補位＋首領出現後繼續混戰，驗證首領實際死亡、角色存活、清怪效率。DPS排名、首領DPS排名、通關生存排名分開。
4. 才開始全合法武器、裝備/卡片最高詞條、屬性及技能組合優化與60組共鳴平衡。正式版仍不修改。
