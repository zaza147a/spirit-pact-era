## 驗收環境

Playwright預設會在自己的CDP連線強制頁面焦點與可見性；另一個CDP連線無法解除原連線的設定。本次在啟動前配置驗收用Playwright，將強制焦點關閉，並由真正的X11視窗管理員最小化／還原瀏覽器。沒有覆寫document.hidden、人工發送visibilitychange或注入時間；事件由Chromium原生發出。此設定只存在於Actions臨時依賴，不修改dist遊戲或使用者環境。前幾輪的環境逾時已由此成功來源取代。
