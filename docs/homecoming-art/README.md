# 十二條返鄉支線：任務美術與敵人

所有變更只在 `feature/companion-homecoming`。正式遊戲未載入此功能，也未部署 Pages。

## 本次素材

- 七張獨立生成的透明戰鬥立繪，WebP 768×768。真正 alpha、四周保留安全邊界；沒有把一張合圖裁成多隻。
- 十二張獨立生成的任務關鍵場景，WebP 1152×768。每條路線一張，用於互動節點，不冒充首次旅行分鏡。
- 來源為內建 imagegen，每一素材單獨呼叫。最終提示詞見 `prompts.json`；技術匯出使用 `scripts/homecoming-prepare-art.py`，只縮放、留白及編碼，保留生成的 alpha。
- `asset-audit.json` 記錄尺寸、位元組數、透明比例與輪廓邊界。
- `dist/homecoming-gallery.html` 可直接展示十九張圖；`dist/homecoming-preview.html` 在任務進行中展示對應場景，戰鬥節點再顯示對手。

## 敵人資料的界線

`dist/homecoming-encounters.js` 提供故事對手的 ID、名稱、等級、HP/ATK/DEF、首領旗標、非致命旗標與 artPath。基礎值以現有曙光怪物為參照，屬草案，尚未做新地圖實戰強度驗收。

敵人不混入原有隨機生怪池，不可捕捉；EXP／金幣／掉落暫為零，沒有沿用曙光首領的任務雜物。`homecomingOpponent(routeId,stepId)` 是後續實際戰鬥接入時的對照入口。

獨立沙盒的勝利按鈕仍為模擬；後續主遊戲整合已接入實際敵人、勝利結算、人物傳承與第四格技能，詳見目前的 `docs/HOMECOMING_FLOW_HANDOFF.md`。數值草案仍需自然戰鬥難度驗收。

## 後續素材

首次旅行的 36 張逐頁圖片已全部接入：原有四張保留，其餘 32 張逐張重繪。成品均為 1280×720、16:9 WebP；本頁的十二張任務場景另計，不抵充旅程分鏡數量。最新狀態見 `../HANDOFF_JOURNEY_ART_PROGRESS.md`，逐張提示詞見 `journey-redraw-log.json`，尺寸與雜湊見 `journey-asset-audit.json`。後續若需要獨立 NPC 對話立繪或各事件的狀態圖，應依遊戲接入後的畫面需求補齊，不複製大量無用怪物。

## 驗證

本次 32 項單元與 DOM 沙盒測試全數通過；十九張 WebP 均以 Pillow 完整解碼，素材合計 5,393,822 bytes（約 5.4 MB）。七張角色立繪的 alpha 與安全邊界均通過匯出檢查，另已檢視角色與場景縮圖總覽。

限定返鄉流程／素材測試：既有任務、第四技能測試，加上圖片路徑、WebP、alpha、八個戰鬥節點對應及非戰鬥節點排除。逐張檢視生成圖與匯出縮圖，並用既有 DOM 沙盒測試點擊與保存。後續已透過 GitHub Actions 完成首次旅程／續讀／抵達／接受委託的真實桌面 Chromium 驗收，詳見 `../homecoming-browser/REPORT.md`。八個戰鬥節點的自然實戰難度仍待驗收。未啟動全職 DPS 矩陣。
