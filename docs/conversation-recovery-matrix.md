## 發布規則

1. 此文件未標「已完整驗收」的項目不得用歷史對話的數字代替新結果。
2. 200等以前可以透過星鑄師逐階強化裝備；平衡驗收**不以是否強化作為限制或必備條件**，並需標明各測試採用的實際裝備配置。
3. 可以保留少數合法強力配置越級，但各等級正常進度裝備的輸出型與防禦型都必須能按角色定位作戰。
4. 完成所有項目後再合併及發布`main`，目前僅更新`feature/humanoid-pet-evolution`。
