# 全職業武器配置有效性規範（隔離測試）

此文件及測試只寫入 `experiment-weapon-balance-20261102`，不修改正式遊戲。

**所有比較配置必須雙手都有裝備**：或者主手持雙手武器（佔用左右手），或者主手持單手武器、副手必須裝盾牌／合法副手武器。沒有空副手、也不允許雙手武器再配盾牌。

| 職業 | 合法、完整測試配置 |
|---|---|
| 騎士 | 單手劍＋盾、單手槍＋盾、雙手巨劍、雙手長槍 |
| 十字軍 | 單手劍＋盾、單手槍＋盾 |
| 巫師 | 單手法杖＋盾、雙手法杖 |
| 賢者 | 單手法杖＋盾、雙手法杖、雙手魔拳套 |
| 刺客 | 主手短劍＋盾、雙短劍、雙手拳刃 |
| 流氓 | 主手短劍＋盾 |
| 祭師 | 單手權杖＋盾 |
| 修羅 | 雙手拳套 |
| 遊俠 | 雙手短弓、雙手長弓、雙手十字弩 |
| 天籟詠者 | 雙手樂器、雙手短弓、雙手長弓 |

流氓「單短劍」及祭師「單權杖」先前屬不完整測試配置，已移除。盾牌作為通用副手依現有 `GEAR_BASE.shield` 檢查；副手短劍只允許與主手短劍配對。

**注意：** 以上為武器佔位及職業可裝備性矩陣；技能能否施放仍需用 `weaponSkillAllowed` 逐項核對，不可將「能穿武器」視作「技能皆可使用」。

後續重新測試職業 DPS、清怪速度和存活率時，所有方案均必須遵守此矩陣，並同時比較僅雙手武器職業的技能收益及生存能力。
