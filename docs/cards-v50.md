# V5 部位卡片與區域特色

固定數值依角色目前等級所屬裝備階段成長，表中以150級示範。百分比與能力值不隨階段膨脹。頭上、中、下提供能力值；全身卡片六項能力值加總最多24，含舊卡。盔甲、披風、鞋子僅提供防禦面效果；武器、副手、飾品提供攻擊、命中、暴擊、穿防與攻速等。

ATK／MATK百分比主要集中武器；副手與飾品分擔固定攻擊、暴擊、暴傷、穿防、魔傷及百分比攻速，避免四部位重複堆同一個攻擊百分比。卡片不隨裝備移動，已鑲能力與卸卡操作位於角色→角色裝備；卡片庫提供未鑲卡片與比較。
