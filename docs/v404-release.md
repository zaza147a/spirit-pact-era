# V4.0.4

- 全部117張卡片指定合法部位，保留既有能力與地圖特色；飾品卡限定飾品1／2，其餘限定單一位置。
- 角色部位卡片與裝備獨立，換裝、卸裝、雙手武器與轉職均保留並持續生效；主動換卡／卸卡才退回。對比裝備時也保留這些卡片能力。
- 讀檔、導入、舊版本遷移自動卸回錯位卡；同ID數量精確合併、合法卡保持不動，重複讀檔不增發。卡片頁提示上次整理明細。
- 每張卡片顯示合法部位、對應比較及鑲嵌按鈕；飾品可明選1／2，新增全卡庫部位篩選。鑲卡函式入口同樣拒絕非法位置，失敗不扣卡。
- 沒有更改卡片數值、技能倍率、裝備強度或加入職業平衡係數。卡片限制會改變實際配裝；效益以實跑總戰鬥貢獻評估，詳見 cards-v404.md。

檢查包含117張卡片及10位置、舊存檔副本退回與冪等性、非法插入無損、空裝備卡位、雙手換裝／卸裝／二轉保留、比較不改狀態，以及現有技能、傷害、離線與存檔回歸。

實測4,320場卡片矩陣與1,440場無卡基準。卡片限位改善不限位堆疊造成的差距，但目前40組差距仍41.58%～53.38%，超過30%；神話人物貢獻比例亦未達35%～45%。詳列結果與各職業變動於cards-v404.md，保留既有無卡基準及完整卡片JSON，不虛稱平衡達標。
