# V3.2：隨機遇怪、玩家技能優先順序與自動捕捉

## 遇怪節奏

各欄位獨立擲隨機時間，進場從0.25～4.5秒改為0.1～0.9秒；一般敵人被擊敗或捕捉後從0.6～4.5秒改為0.25～1.4秒。沒有等整波打完再補怪，亦不按固定欄位逐隻填滿。欄位上限、額外首領欄位與首領冷卻不變；快速清怪時更容易感受到敵人連續進場。

## 自動技能設定

位置：職業技能頁最上方的「自動技能優先順序」。已學習的一、二轉主動技能列在同一份可排序清單，可逐招啟用或關閉，使用上下箭頭調整。順序及開關由每個角色獨立保存，匯出、導入和離線結算一併沿用。新職業技能加入清單但保留原本已設定順序。重置技能不清除偏好；未學習技能不會施放。

每次由上往下找可用技能：冷卻、SP不足、武器不符會略過；選到一招成功施放就結束當次選擇。不再在玩家順序之前強制二轉、增益或高效招式優先，也不強制禁止武僧使用已學習的一轉魔法。

治療仍在角色HP65%以下才嘗試，聖域也會考慮活著的寵物；回魔在SP55%以下；護盾在角色HP85%以下且現有護盾不足時；增益不在原效果仍有效時重複施放。手動技能按鈕不受自動開關限制。

連發技能若排在最前，且每次判定都已可用，可能持續佔用施放機會。這是玩家設定的實際取捨；希望先放其他招時，請將連發技下移或停用。系統不會暗中改回自認為最強的排序。

## 寵物之地自動捕捉

位置：掛機設定 → 寵物之地自動捕捉。可分別勾選攻擊、魔法、防禦、輔助型，預設全部關閉。開啟自動戰鬥、位於寵物之地且遇到選定類型時，最多每秒嘗試一次丟球，不需降低HP，先於當次人物和寵物攻擊。未選類型照常戰鬥。

沒有捕捉球時沿用每次補購一顆的規則；金幣不足、寵物滿30隻時不再花錢丟球，不自動放生。城鎮、其他地圖、首領、暫停自動戰鬥與離線結算均不自動捕捉。既有罕見以上捕捉提示及保護規則維持。

## 平衡數據的解讀

比較對象是所有10職業×4寵物共40配對，取三情境綜合分數的最高與最低；不是只算某一職業內四寵差距。「每職各自最佳配對差距」另取每職最強的一組，再比較10組。

本版可自訂技能優先順序，各種自訂設定不保證相同戰力，也不自動最大化。既有V3.1的原始720場報告另存為balance-v31.json；本版報告使用預設技能順序與新的遇怪速度，不能將歷史排名視為每個玩家設定的最佳路線。

## V3.2.2 人物資訊調整與捕捉上限修正

Base Level／Job Level以34px等級數字及獨立資訊卡呈現，EXP靠右。人物能力配點移到人物資料正下方、出戰寵物之前，保留折疊狀態，增加「分配給上方人物角色，非寵物能力」提示。人物與寵物使用分開的DOM容器，視覺和閱讀順序一致。

人物介面部分僅修改render()內的HUD與HTML／CSS；另修正寵物之地自動捕捉上限。已比對其餘戰鬥程式與其他JS模組均與V3.2相同，三個平衡測試情境不啟用寵物之地捕捉，因此保留原720場戰鬥資料，更新來源指紋並附驗證說明。

公開版實測另發現原有手動捕捉上限為30隻。自動捕捉守門及提示已統一為30隻，避免欄滿後每秒重複呼叫手動捕捉並跳出訊息；保留既有存檔允許的較大資料容量，不刪除既有寵物。此修正只涉及寵物之地自動捕捉，三個平衡測試情境均不啟用此功能。
