# 靈契紀元 V3.0：職業、夥伴與冒險規則

本版取消職業／寵物種類的整體傷害係數。面板能力直接由基本屬性、Job、裝備、卡片與被動形成；傷害由公開技能倍率、冷卻、武器限制與實際戰鬥機制決定。

## 屬性與職業

基本配點上限99；超出的舊配點退回未分配點數，裝備、卡片與Job加成不受99限制。顯示為「基本值 + 額外加成」，例如99 + 78。Job加成隨Job Level逐步取得；二轉保留一轉當時取得的Job加成。一轉Job40提早轉職，與Job50轉職保留的技能預算及Job加成不同。

舞孃／獵人／弓箭手依DEX提升ATK；法師、巫師、賢者、服事、祭師依INT提升MATK；魔法職普攻也使用MATK。十字軍盾擊用ATK與DEF、武僧與刺客等物理職依STR。DEX對ASPD的次要加成縮小，避免同時獲得物攻、命中與過大的攻速優勢。

城鎮技能頁可分別重置屬性或技能，每次費用1000 + Base Level × 100金。完整退回已投入點數，重置技能分別回到一轉／二轉池，保留各分支起始一招，並扣回該招占用的一點。不重置職業、Base／Job等級、裝備或寵物。

一轉與二轉技能分成獨立區塊；圖鑑不再混入技能配置。AOE逐一對目標造成較低的單體倍率，範圍技能不再分攤傷害池，也不會被主目標剩餘HP限制其他目標傷害。巫師最多4～5目標，其他範圍技能多為3目標；單體技使用較高對單倍率。樂器不再施放弓箭技能，仍可換弓使用保留的一轉箭技。

## 寵物、裝備與掛機

- 寵物死亡不獲得經驗，死亡後3秒內不能用藥水復活，也不會靠升級恢復生命。
- 寵物可鎖定；鎖定禁止單隻或批次放生。批次放生另外保護出戰寵物。
- 寵物裝備集中配裝預算：頭部對應一把主要武器的攻擊預算，其餘一般屬性按10/3集中到三件裝備，身體與腳部承接大量生命、防護、命中與迴避。不是給予三把武器的傷害；同階三件寵裝可提供接近整套角色裝備的綜合能力。
- 角色／寵物一般裝備掉落機率18%／2%，相對比例9：1；首領保證一件罕見以上裝備，90%角色裝、10%寵裝。首領卡片仍是0.1%。寵物裝備需求雖少，取得速度也相應較慢，並非完全等時取得。
- 角色與寵物護盾各上限自身最大HP25%，6.5秒消退，守護自療降低；怪物傷害有35%攻擊力的最低傷害底線，避免DEF堆疊到近乎無傷。狀態欄直接顯示護盾。防禦寵仍以承傷、護盾、反擊與保護為主。
- 玩家／寵物HP、SP四項可獨立指定藥水、由高效到低效或由低效到高效；指定藥水不足時回退到最高效的現有藥水。沿用各自1～100%補給門檻。
- 自動戰鬥預設開啟；只有手動停止會記住手動暫停。金幣不足的自動復活另記停止原因，避免重新進入後自行冒險。
- 可開啟金幣自動復活，線上／離線一致；有足額金幣便原地恢復50%HP／SP，金幣不足免費回城並停止。寵物仍遵守3秒復活等待。
- 記住上次目的地，可按「再出發」直接返回。
- 換下、卸下或從放生寵物退回的裝備加上換裝保留，自動分解不會處理；可自行解除保護或手動分解。裝備UID與卡片會保留，既有裝備不會因換裝被覆蓋丟失。

## 稀有度與特殊詞

傳說金字、神話紅字。特殊詞只出現在神話：5條一般詞＋1條特殊詞。傳說5條均為一般詞，仍有較高核心數值。舊裝備依新規則換算，保留UID、稀有度、階段、融合保護、換裝保護及可保留的一般屬性種類；不刪裝備或玩家進度。

- 防具特殊詞：FLEE%／最終減傷%／HP%。
- 武器特殊詞：ASPD%／暴擊機率%／暴擊加成%／無視防禦%。
- 同階詞綴以參考情境的有效生命或輸出增幅作預算，VI階參考為HP約8%、減傷約7%、FLEE約22%，武器攻速約8%、暴擊機率約24個百分點、暴傷約20個百分點、無視防禦約16%。
- 效益會隨原本暴擊率、敵人防禦、技能占比及上限而改變，不能保證所有裝備組合中完全等效。最終減傷累計最多40%，暴擊最多100%，無視防禦最多60%，額外攻速仍有80ms最小攻擊間隔。

## 冒險與圖鑑

每一個普通遭遇格有自己的隨機出現／補位時鐘，互不等待；空格保留探索占位。首領仍是額外的一隻獨立怪物。51級以後的怪物生命提高，首領生命為同區一般模板的6倍；1～50級新手區公式不變。

世界圖鑑分為共鳴玩法、寵物進化／技能、職業技能參考、各區卡片特色。進化祭壇只保留進化與材料操作。一般進化外觀仍只展示普通、稀有、罕見；傳說與神話只給進化提示。捕捉到罕見以上時，跳出帶寵物圖像的恭喜視窗。進化過程使用白色輪廓、共通光核和逐漸變形，最後才顯示結果，不依是否變異提前洩漏外觀。

## 驗證範圍與限制

完整戰鬥審核保存在 balance-v24.json（檔名沿用，資料版本為30）。每個配對採合法99點基本屬性、匹配的罕見裝備、固定技能預算、IV3、無卡片、自動藥水與終極共鳴。40配對 × 3場景 × 2品質 × 3種子 = 720次，每次120秒；場景為真實遭遇、持續首領、持續四怪。等級與收益在審核內凍結，固定裝備衍生值可快取；冷卻、增益、死亡、復活等待與護盾到期使用真實combatTick。

本次移除了舊版用整體係數壓平的結果。

**未達成的舊目標會如實記錄：所有40配對差距≤30%，以及神話主人貢獻35～45%，目前不是全面達標。** 每個職業最佳配對的差距、全部配對差距、角色／寵物貢獻、死亡與藥水消耗均保留在審核資料。防禦與輔助不以提高直接傷害硬湊攻擊寵傷害；數值調整仍需以技能、專屬武器與實際生存、資源效率繼續迭代。不能把有限的固定配裝審核當成所有配點／裝備／技能的最優解證明。
