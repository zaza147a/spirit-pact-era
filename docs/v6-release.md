# V6.0.0 蒼穹彼岸與雙靈覺醒

重新整理正式網址即可載入；四個獨立存檔沿用。

## 死亡與大陸

人物死亡後，原地復活與免費回城復活均等待15秒。手動藥水無法繞過人物復活；自動金幣復活與離線模擬亦計入等待。寵物死亡後等待10秒，手動／自動補給及人物復活帶起寵物皆遵守。倒數保存在存檔，重載不會重置或跳過。

新增大陸下拉選單：伊卡洛斯大陸1–99、蒼穹彼岸101–200。蒼穹樞城為新大陸主城，三轉、融合進化與商店皆在此，新大陸回城返回樞城。

## 三轉

150級獨立首領「天極斷界龍」5%掉落「天極覺醒聖印」。收集10枚、人物Base150／轉生二轉Job70，可向蒼穹樞城覺醒導師・賽菈三轉。沿用既有預備道具ID，舊存檔已收集數量完整保留，名稱統一更新；其他等級首領不再掉三轉聖印。

三轉保留Base、配點、裝備、卡片、舊技能與各舊點數池；Job回到1，上限70。初始主攻1級，之後每Job等給1點。五主動×10級＋四被動×5級＝70點，Job70可以點滿新技能。人物三轉才開放151–200級。

## 雙靈融合

兩隻不同系列、150級、完成界限進化的神話寵物，可在蒼穹樞城融合。需先解除鎖定，無額外金幣／材料費。主素材保留自身裝備、ID與忠誠度，融合後等級150、EXP歸0；IV取兩素材平均向下取整。副素材永久消耗，副素材裝備退回背包並加保護；背包容量不足不會執行。確認視窗列明永久消耗，沿用4秒輪廓漸變動畫與完成提示。存檔失敗會回復整筆交易。

只有融合後寵物才能升151，上限200；人物三轉不會自動替寵物突破150。六種配對各3招專屬技能、可裝備2招。順序只改外觀與名稱，能力模板、技能、距離、共鳴一致。
