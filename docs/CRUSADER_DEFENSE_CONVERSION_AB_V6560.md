# V6.5.60 十字軍 DEF 轉傷上限 A/B 實測

## 範圍

- 測試原型基底：正式版 `main` V6.5.60，未更動正式版。
- 試驗變更只影響十字軍 `source: shield` 與 `source: holyShield` 的攻擊來源，令 `effectiveDEF = min(actualDEF, ATK × 4)`；其他職業、防禦、HP、MDEF、最終減傷均不變。
- 使用既有 `legal-210-survival-first/crusader-210-sss-sigil8-legal.json`，保留契印 8、角色與夥伴裝備、王卡和技能、HP/SP 自動補給四項 90%。
- 每組三次種子 11、29、47，同時測試單體高血量敵人 60 秒及真實地圖生怪 120 秒。

## 高壓承傷 A/B（60 秒）

固定怪物 ASPD 150；兩版本使用相同測試存檔、攻擊力與隨機種子。

| 攻擊模式 | 敵方攻擊力 | 原版死亡種子 | 新方案死亡種子 |
|---|---:|---|---|
| 物理 | 330000000 | 0/3 | 0/3 |

此驗證支持「防禦轉傷不改變承傷公式」，但不代表物理 3.8 億或魔法 1.45 億是精確死亡臨界值。種子採樣有限。

## 平衡判斷

測試候選明顯降低過強的 DEF 輸出，卻不犧牲十字軍的坦度。其單體輸出降幅接近 48%，清怪量降幅約 36%；是否過度削弱，需要再和其他九職業同條件的實際清怪 DPS 作橫向比較。目前僅屬候選，不發布 `main`。
