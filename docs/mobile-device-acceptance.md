# 實體手機／Safari 驗收操作包

狀態：**待實體裝置執行**。Chromium／WebKit 自動化不能替代實機結果。此流程只在本機／區域網路測試功能分支，不需要合併 main 或發布。

## 準備測試網址與存檔

1. 使用 `feature/humanoid-pet-evolution` 最新版本，在專案根目錄執行：

   ```sh
   node scripts/browser/export-device-fixtures.mjs
   python3 -m http.server 8766 --bind 0.0.0.0 --directory dist
   ```

2. 電腦用 `http://127.0.0.1:8766`；同一可信區域網路的手機用 `http://電腦區網IP:8766`。若系統詢問防火牆，只允許目前私人網路。測完停止伺服器。不對外開埠。
3. 四個基本 QA 存檔與一個連戰失敗專用檔位於 `browser-qa/device-fixtures/`，也隨瀏覽器驗收 CI 截圖 artifact 一起提供。前三格各包含12有序融合的 S、SS、SSS 夥伴，第四格為忠誠度500的A階進化測試；是測試配置，不是正常遊玩取得證據。
4. **只在上述測試網址匯入**；先匯出該網址既有存檔，避免覆寫其他角色。不要匯入正式站點。四個檔案依檔名前的slot編號匯入四格。

點擊已出戰夥伴會「收回」，不是再次選取；驗圖時先確認牠處於出戰狀態，或先切至另一隻再切回。

## 操作與通過標準

| ID | 操作 | 通過標準 | 實機結果 |
|---|---|---|---|
| D01 | 四格匯入、重新整理、關閉重開 | 四個名稱、格間角色／夥伴不互相覆蓋 | 待驗 |
| D02 | 第一至三格各切換12隻夥伴 | 36張S／SS／SSS圖片與名稱正確，無破圖、無裁斷主體 | 待驗 |
| D03 | 每格點角色／夥伴／設定與管理／當前戰鬥夥伴 | 觸控一次只觸發一次，沒有固定欄遮擋或無法點擊 | 待驗 |
| D04 | 直向與橫向切換、上下滑動 | 無頁面橫向溢出；頂部存檔、返回及頁籤仍能操作 | 待驗 |
| D05 | 打開手機鍵盤輸入補給數量37，收鍵盤 | 游標不跳走、37保留；不被戰鬥刷新覆寫或遮住必需操作 | 待驗 |
| D06 | 第四格進入忠誠度演出，等待完成 | 四秒演出結束後完整彩色幼年圖、關閉可用；關閉重開不重複消耗 | 待驗 |
| D07 | NPC逐階把夥伴三件裝備由A升S、SS、SSS | 每階完整進化；每階花掉三份相應核心，不跳階、不顯示undefined | 待驗 |
| D08 | 匯出第四格，重新匯入並進入 | SSS不可逆階段、技能三選及順序、裝備保留；下載及檔案選取可用 | 待驗 |
| D09 | 回野外開自動、存檔，切背景至少11秒再返回 | 只結算一次真實離線進度；另外三格不變；結算視窗可關閉 | 待驗 |
| D10 | 戰鬥中在設定輸入框輸入、選字、刪改 | 真實鍵盤、中文組字及焦點不因即時刷新中斷 | 待驗 |
| D11 | 匯入自備已解鎖連戰、兩張券的弱勢角色，讓第一輪戰敗 | 只消耗一張券，戰敗停止；等待16秒不自動復活重入；再次重開仍停止 | 待驗 |
| D12 | 完成後再檢查四格、匯出備份 | 全部可存讀；測試原站點及正式站點資料不受影響 | 待驗 |

D11使用`continuous-failure-QA.json`，在第四格完成D08並匯出後再覆蓋第四格；此檔已有連戰資格、兩張券、無裝備／夥伴且HP為1。自動CI使用同一個測試存檔產生函式，但CI成功不是實機通過。

失敗時記錄ID、SHA、裝置／瀏覽器、操作步驟、預期與實際結果及截圖；修正後重測失敗項及同一流程相鄰步驟。只有附上實際結果才能更新「待驗」。
