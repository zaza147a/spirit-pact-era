# 御靈使（第 11 職業）獨立開發規格 — 2026-11-03

> 狀態：規劃／未實作。僅允許在 `feature/spirit-tamer-dual-pets` 分支修改與測試。不得合併 `main`、不得更新正式站，直到使用者明確指示。

## 轉職與養成
- 一轉「御靈使」即可攜帶兩隻夥伴。
- 二轉分流：「靈契戰使」（人物主攻、夥伴個別選擇同化／協戰）與「雙靈指揮官」（雙夥伴主攻）。
- 進階二轉延續選定路線，前期技能只需針對四種基本非融合夥伴設計與平衡；提早取得的融合夥伴仍可使用，不啟動三轉專屬效果。
- 三轉：「靈契君王」／「萬靈宗師」。必須同時配置**兩隻融合夥伴**並完成專屬「雙生靈契」支線／試煉，才允許轉職與解鎖後續三轉進度。
- 六種無序融合類型的雙寵配對為 21 組（允許同類配對）；君王 21 組同化特色、宗師 21 組雙靈共鳴。
- 不額外要求 S/SS/SSS 才能轉職；融合寵既有等級、忠誠、裝備、卡片與進化資料保留。卸下一隻融合夥伴不退轉，但無法啟動依賴雙融合的三轉效果。

## 職業專屬裝備掉落被動（提案，需驗證現有實作）
現行人物裝備：夥伴裝備 = 9:1（使用者提供，尚待從程式驗證）。改為御靈使職業被動「靈契尋寶」：
- 推薦：一轉及二轉為 **8:2**；進階二轉及三轉為 **7:3**。此為提案，使用者尚未選定 7:3 或 8:2 的實際生效階段。
- 只有在「本次已確定掉落裝備」之後才調整裝備類型的條件機率；**絕不增加整體裝備掉落機率、件數或階級，也不影響金幣、卡片、材料、首領保底或專屬掉落**。
- 其他十職業維持 9:1。判斷使用目前角色的職業，而非帳號或倉庫；不追溯改動既有裝備。
- 特殊掉落表中明確指定人物／夥伴裝備者保留其指定類型；僅對共用裝備類型抽選流程套用分配比例。
- 避免重複加成、雙夥伴各觸發一次、角色切換造成掉落類型錯誤；離線掛機／連續戰鬥需共用同一判定核心。
- UI 將效果明確標為「已掉落裝備之類型比例：人物 80%／夥伴 20%」（進階後為 70%／30%），非裝備總掉率。

## 平衡驗證
- 一轉、二轉、進階二轉、三轉初期、三轉完全養成逐階段比較現有十職業同等級／裝備／夥伴培養。
- 200 等試煉五連戰、210 等 201～210 地圖含首領；合法配點、卡片、裝備與技能；契印 0、減傷上限 40%、實際 ASPD／暴擊期望／穿防。
- 人物自身、夥伴 1、夥伴 2、共鳴以及總 DPS 分列；同時測清怪時間、死亡、承傷、首領時間。
- 靈契君王 21 配對 × 4 個同化／協戰狀態；萬靈宗師 21 配對 × 3 個指揮模式。須測不同階級養成與合法最佳化配置。
- 避免新增職業在單體 DPS、群怪效率和生存三項全面壓過既有職業；盡量在既有職業前列的可接受範圍，並依戰術特長取捨。
- 調整新職業第二寵傷害係數、同化收益、技能倍率和共鳴內部 CD；不為新職業修改怪物難度或削弱既有十職業。
- 所有共鳴造成的傷害不可再次觸發共鳴；裝備／卡片增傷不得重複套用；兩隻夥伴有各自 HP、SP、CD、目標與死亡狀態。
