# V4.0.4 卡片部位與效益

卡片綁定角色部位，換裝、卸裝、轉職與雙手武器都保留並生效；每部位一張。換卡會將舊卡退回，手動卸卡也會退回。沒有裝備也能鑲卡。

## 效益解讀

- ATK%、MATK%、HP%、SP%、DEF%、MDEF%、FLEE%：各自的卡片加成先加總，再依現有能力公式套用；不可把面板增幅直接等同整隊戰鬥貢獻增幅。
- 暴擊傷害 +1%：暴擊由現有傷害×1.40改為×1.41；並不是所有攻擊都提高1%。暴擊率另受100%上限限制。
- ASPD：按實際攻擊間隔計算，193為上限；有詠唱／固定CD的技能不會因此同等加速。
- 無視防禦：只對對應物理防禦有效，依當前60%上限計算；與魔法傷害不是同一項能力。
- INT／DEX：同時可能影響MATK、遠程ATK、命中及詠唱，視職業與技能而定；本版比較顯示實際人物能力變化。
- 負面HP、DEF、FLEE、HIT或ASPD完整保留。防禦／輔助寵以有效承傷、減傷、治療和增益傷害評分，不要求直接傷害追平輸出寵。

## 模擬範圍

同一套固定罕見人物／寵物裝備、職業配點與技能優先序，評估一般99級與轉生120級、罕見與神話寵物、單怪／首領／多怪、三個固定種子。每場120秒，40職業×寵物組合，分別採無卡片、舊版不限部位、新版指定部位，共4,320場。另重新執行1,440場既有無卡片基準。

兩種插卡規則使用相同的兩輪座標貪婪選卡方法，依傷害、暴擊、詠唱、攻速、穿透與較低權重的有效生命／SP代理分數選擇，再實跑戰鬥。測試假設所有仍可掉落卡片供應充足，排除八張舊版已停止掉落卡，並非農卡成本評估，也不代表窮舉最佳／最差玩法。兩組都使用相同十個角色卡位，以隔離「限制部位」的差異。

完整原始結果：`docs/card-balance-v404.json`；選卡、各卡片面板增減、各場種子與總貢獻皆保留。總貢獻包含有效傷害、有效治療、減傷與實際消耗護盾，不將溢補或未用完的護盾當作貢獻。
