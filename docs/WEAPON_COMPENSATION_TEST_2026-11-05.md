# 武器改版補償・測試版驗收

## 功能

- 只在首次讀取舊角色存檔時，記錄該角色**已裝備或背包內**是否持有 Lv190～200 角色武器；之後取得的武器不會追加資格。新創角色不符合資格。
- 同一角色只能領取一次，可延後領取；與其他角色格的資格互不影響。補償不會刪除既有裝備。
- 登入角色 → 完成離線掛機結算 → 關閉離線獎勵 → 顯示武器補償彈窗 → 選擇合法本職武器／詞條 → 確認領取。首領卡片公告仍依序顯示。
- 原先持有的最高等級武器決定補償物的等級、稀有度與原強化階級；例如 Lv200 神話 SSS 拳刃可領同級神話 SSS 的本職武器。原有武器仍保留。
- 一般詞條數量依品質限制，主詞條與 HIT 固定，其餘可由六素質中選取，不可重複。神話附加特殊詞條僅可從「攻速加成、暴擊率、暴擊傷害、最終減傷」擇一。顯示武器固有特性，固有特性不隨 SSS 放大。
- 刺客可選拳刃、主手短劍，或一次領取「主手短劍＋副手匕首」雙短劍組（各自獨立自選詞條）。修羅只列雙手拳套。

## 測試檔案

- `dist/weapon-compensation-test.html`：測試站入口，會將測試存檔寫入目前瀏覽器第一格，並轉至遊戲 `index.html`。可下載即時更新離線時間的測試存檔。
- `dist/test-saves/weapon-compensation-assassin-200.json`：210 等刺客、200 等神話 SSS 拳刃的舊版模擬存檔（未設補償領取旗標）。
- `tests/weapon-compensation.test.mjs`：一次性、防重領、合法職業、雙短劍、特殊詞條限制。

## 部署範圍

這一輪只放在 `feature/weapon-balance-v6547-2026-11-05`。**沒有更新 `main` 或正式 GitHub Pages**。倘需公開網址的獨立測試站，必須先配置不會覆蓋正式站的獨立託管位置；不能把正式 Pages 指向測試分支。

## 風險與後續

- 目前為本機 JSON 存檔制；未經伺服器簽章的舊存檔無法密碼學地證明其建立時點。資格以首次升級載入時的既有武器為基準，降低改版後新掉落混入的機率。
- 測試站入口會覆蓋同來源網站第一角色格，請使用獨立網域或無痕視窗驗收。
- 共享倉庫內的武器未列入資格判定，避免其他角色共用一件武器而重複領取。
