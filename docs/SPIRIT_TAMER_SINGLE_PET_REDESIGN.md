# 御靈使單夥伴重製規格（獨立測試分支）

狀態：設計基準；尚未完成程式實作。分支 `feature/spirit-tamer-single-pet`，不得修改或部署 main。

## 共通規則

- 御靈使及其二轉、三轉職業皆僅有一個 `activePetId` 出戰欄位，與其他十職一致。
- 舊存檔 `secondaryPetId` 指向的夥伴仍保留於 `pets` 收藏清單，完整保留等級、裝備、技能與稀有度；載入時清除第二出戰狀態，不放生、不刪物品。主出戰夥伴仍保留。
- 取消第二夥伴配置按鈕、雙夥伴戰術／報表／UI／戰鬥回合；所有實際戰鬥、離線 Worker、五連戰與重載存檔都必須只處理一隻夥伴。
- 共鳴使用現有四基礎類型（攻擊、魔法、防禦、輔助）及六種無序融合（攻魔、攻防、攻輔、魔防、魔輔、防輔），融合順序不改數值。
- 二轉起開放四類基礎共鳴，三轉依融合類型切換為六套進階共鳴；每職同時僅啟用一套，避免多套疊加。共鳴強度以合法存檔與實戰 Worker 驗證，數值須另行平衡。

## 靈契戰使 → 靈契戰將 → 靈契君王（代碼 pactWarrior）

定位：**人物輸出、夥伴同化**。進入同化後，該夥伴不能普攻、不能主動或自動施放技能，不能觸發夥伴傷害、寵物攻擊卡、協戰傷害、寵物 DPS 歸屬。夥伴能力轉為人物身上的同化加成；人物自身技能、攻速與卡片仍正常運作。失去夥伴或夥伴倒下即失去同化，且所有轉移只計一次。二轉後固定同化，不提供協戰姿態切換；一轉御靈使沿用一般單夥伴戰鬥。

二轉四基礎共鳴（具體倍率待實測）：

| 類型 | 共鳴 | 效果與差異 |
| --- | --- | --- |
| 攻擊 | 戰魂灌注 | 同化 ATK／HIT；人物連續命中累積層數，下一次主攻消耗層數增傷 |
| 魔法 | 靈術迴路 | 同化 MATK／施法效率；人物施放技能輪替元素印記，下一次對應攻擊引爆 |
| 防禦 | 鐵血承契 | 同化 DEF／MDEF／HP；承傷後短暫提高人物傷害與抗壓，設觸發冷卻 |
| 輔助 | 生命誓約 | 同化恢復與支援能力；人物施技後短暫獲得傷害／續航增益，不產生夥伴施法 |

## 雙靈指揮官 → 雙靈統御者 → 萬靈宗師（代碼 spiritCommander）

定位：**夥伴主輸出、人物協戰與增益**。只有單隻出戰夥伴能普攻、施放寵物技能及造成主要傷害。人物攻擊保留較小但有意義的支援／標記功能，不應以人物傷害超越夥伴。人物能力、裝備與已裝備卡片的相關效果可轉移給該夥伴，但須依效果類型映射、共用上限與觸發來源，**不可主人與寵物重複結算同一張卡**；不可將不適用的卡片（例如指定人物特定武器施技條件）無條件複製。轉移數值的最終戰鬥效果需明示於 UI。

二轉四基礎共鳴：

| 類型 | 共鳴 | 效果與差異 |
| --- | --- | --- |
| 攻擊 | 獵令協戰 | 人物命中標記目標，使夥伴下一次攻擊追加破甲／追擊 |
| 魔法 | 秘法供能 | 人物 MATK／施法增益轉為夥伴技能強化，夥伴施技累積充能 |
| 防禦 | 守護輪替 | 人物 DEF／MDEF／HP 部分映射夥伴；夥伴承傷後獲得短時保命效果 |
| 輔助 | 契約增幅 | 人物治療／Buff／卡片支援詞條轉為夥伴攻速或技能效率，避免無限疊加 |

## 驗收條件

1. 既有雙夥伴存檔重載後只有一隻出戰，第二隻保留在背包／夥伴列表，所有裝備技能無遺失。
2. 君王在自動、手動、離線、試煉中：夥伴實際傷害恆為 0、夥伴技能施放次數恆為 0；人物正常享受唯一一次同化。
3. 萬靈在所有戰鬥路徑只使用一隻夥伴，人物裝備／卡片效果轉移須有防重複測試。
4. 二轉 4 套、三轉 6 套共鳴各具正反案例，且無序融合方向結果相同。
5. 保留十個舊職業原本的單夥伴行為；自動測試必須通過，平衡／DPS 大型測試待新機制完成後手動啟動。
