# 第三輪：全職業武器傷害敏感度與待測補正

日期：2026-11-02；分支：`experiment-weapon-balance-20261102`。**不得合併 main，使用者尚未授權正式發布。**

## 范圍與效力
本報告是**受控的武器攻擊週期代理模型**，不是實際遊戲引擎完整 DPS。已從正式原始碼核對：`affixRange`、`THIRD_MAIN_CURVES`、`aspdAttackIntervalMs`、`outgoingHitDamage`、`incomingMonsterDamage`、`ENHANCEMENT_POWER`。忽略真正 `game.js` 的技能排序、法術詠唱、冷卻、Buff、屬性、卡片、命中、暴擊、融合共鳴、夥伴、存活及實際技能可施放限制；尤其巫師的真正攻擊週期有詠唱，不能把此表當成巫師實戰 DPS。

- 人物 Lv200、神話界源階、SSS×3.2，同職業共同假設其餘攻擊 3000，敵防禦 6500。
- 第三轉主攻倍率取等級200的職業曲線，Rank10 係數 1.72、二三轉倍率 1.4。
- 假設單手 ASPD 193、雙手扣3後190，攻擊週期各為 140ms、200ms；這是測試邊界，不代表實際人物面板。
- 候選測試：雙手主攻擊詞條 +40%、刺客副手短劍計入45%，但**仍保留雙手-3攻速**。不修改正式數據。
- 關於 50、100、150 等低等級案例：基準程式套同一個200級三轉曲線作武器敏感度，不代表角色在低等級已習得三轉技能。這些案例不得作為實際DPS排名。

## 本輪確認的問題

1. 雙手主詞與單手相同，無法補償缺少盾牌或副手武器的巨大收益；如果雙手速度另有代價，必須再用具體職業增益判斷。
2. 刺客三流派必須定義不同的勝出場景，而非把三者的60秒輸出拉到同一水準。後續需測：雙短劍60秒毒傷、拳刃8秒爆發與清三四怪、短劍盾存活率與反擊。
3. 同主攻屬性的弓種和劍／槍沒有詞條上的差異，應靠不同技能機制、速度、觸發、爆發與射程受益區分，不能只是換外觀。
4. 一律加40%攻擊只是敏感度測試：仍需測攻速193上限、限雙手職業存活和高階盾牌防禦飽和。不要把 +40% 做成正式全職業規則。
5. Lv200／210 的全部10職 × 6無序融合=60組共鳴、首領與三四體、SSS/無強化、卡片與玩家/寵物正確傷害歸屬尚待完整迴圈重測。

## 後續重測優先順序
1. 真實三轉技能循環（8秒爆發／60秒維持）、屬性、穿透、暴擊、MP與冷卻。
2. 三流派刺客效果實裝於測試分支，並以同怪物長短戰及多體清圖比較。
3. 巫師／賢者實際詠唱與攻速、武僧拳套、獵人三弓、天籟樂器與弓的區分。
4. 無序融合6組 × 10職完整60套共鳴：確定能力對稱，並驗證實際傷害歸屬。
5. 151–200試煉與200尾王、201地圖與210首領的勝率／進度門檻。
6. **取得全部測試通過與差異表後**，才提出供使用者批准的正式版補正。
