# V4.0.3 操作與資訊修正

- 掛機雜物出售新增全部勾選／全部取消，並提供各分區全選／取消。使用原有出售邏輯，保留已接任務100個指定雜物；誓印、裝備、卡片不會因全選被賣掉。設定按角色儲存。
- 暴擊計算確認：人物與寵物基礎140%，+1%為141%（×1.41），+10%為150%。新增實際攻擊測試，控制同一裝備、個體值、敵方防禦與隨機倍率，驗證一般命中與暴擊比例；不使用1.4再乘增加百分比。傷害公式沿用V4.0.2，仍是先扣防禦、再90–110%浮動，最後套暴擊。尾刀實際扣血最多為剩餘HP，紀錄仍分列命中傷害與有效扣血。
- 魔力拳資訊並未遺失傷害計算：之前將文字改為「命中傷害」後，非暴擊紀錄不再命中文字分類規則，被列入其他訊息。本版人物攻擊／施法／治療／護盾／增益，寵物普攻／施法／持續傷害均明確指定紀錄分類。魔力拳非暴擊會正常出現在人物攻擊。
- 人物目前技能的名稱、等級、SP、倍率、CD、ASPD動作間隔改為常駐資訊，不需滑鼠懸停或展開面板。顯示武器不符、SP不足、詠唱、冷卻、共用動作間隔等狀態。修正二轉新角色或失效預設技能錯選未學一轉技能的情況，保留使用者有效的既有選擇。
- 新增常駐任務追蹤，顯示雜物／100與誓印／10；收齊後醒目提示可回村找艾琳回報，並提供回村按鈕。通知以任務狀態記錄，避免每次戰鬥反覆提示；離線收齊後進入遊戲才提示。
- 卡片庫新增比較部位選單。各卡片列出目前插卡與新卡效果，並依人物當前裝備、Job、其他卡片及已生效增益計算換卡後總能力增減。預覽以try/finally還原原插槽，不消耗卡片、不改HP／SP。鑲卡按鈕鎖定在同一個比較部位，避免比較與實際操作不一致。

本版沒有更動傷害倍率、攻擊公式、技能自動排程或怪物強度。另修正12種非預設護盾技能的保護目標，優先以70%額度保護寵物、餘額給主人，各自最多25%HP並持續6.5秒；冷卻時顯示兩者目前護盾量。新增三個技能家族×四角色的實際護盾測試，確認主人護盾已滿時仍可保護寵物。預設1440場矩陣使用的雙技能不包含這12種護盾技能，防禦寵的預設守護原本已保護自身，未更動。沿用原預設配置資料並明確記錄此範圍限制，不把它當作新護盾配裝的完整平衡結果；原本未達標的整體平衡限制仍保留。
