# V6.1.2：三轉技能配置與151–200難度複核

已修正十個職業共50招三轉主動技能在自動排序中誤標為「一轉」。技能選擇會保留到新增，面板更新不會把選項改回第一招；新增、移除、上移／下移及存檔正規化均納入回歸測試。逐影者另以瀏覽器實際匯入測試角色、選擇「奪命斷影」、移開焦點、再新增，確認技能名稱與三轉標示一致。

## 實測結果

共5,100組真實戰鬥迴圈模擬，十職業×六種融合配對。使用V6.1已選的三招融合技能，人物排序固定為生存／姿態／主攻／範圍／終結，並非重新窮舉全部寵物技能排列與人物優先順序。90%參考配置以「前一階頂級神話裝備詞綴、合法配點及可取得卡片」同步縮放；融合寵裝備同樣縮放，寵物IV固定3。這是可重現的配置定義，不代表每項最終面板能力恰好等於理論最大值90%。

一般戰鬥每組120秒，場上四隻隨機當區小怪，擊敗即持續補怪。151／160、161／170、171／180、181／190、191／200共十個等級，各三個種子42、731、2026：

- 90%配置：1,800／1,800存活。各等級六十種配置的三種子平均清怪速度差距17.8–25.6%，均小於30%。寵物戰鬥貢獻約60.7–64.4%，包含傷害、承傷、護盾、有效治療與增益。
- 70%配置：五個區域入口共300組，211組存活；每區只有40–45／60種配置存活，平均每分鐘約11.2–16.2隻。
- 100%配置：五個區域入口300／300存活，平均每分鐘約37.7–55.6隻。70／100%各用種子731，僅作強度門檻對照；此處不宣稱它們或任意技能排序也符合30%差距。

首領測試使用正式怪物血量，而非舊診斷用固定10億HP。首領與四隻隨機小怪同場，使用實際隨機空格補怪，最多240秒，擊殺首領或人物死亡即停止；同歸於盡不計勝利。

## 方法限制與重跑

模擬不發EXP／掉落、不升級、不自動復活，人物及寵物初始滿HP／SP，備有9,999瓶大紅及大藍。補藥消耗包含在原始結果，不代表金幣或補藥能永久自給。區域一般測試的補怪密度用於比較清怪能力，首領同場測試才使用實際空格隨機遭遇迴圈。本次沒有更動職業技能倍率、融合技能或共鳴；不把怪物變強誤稱為所有技能排序都已重新平衡。

執行：`node scripts/audit-frontier-v612.mjs`。預設重新模擬全部5,100組。`FRONTIER_REUSE_SAMPLES=1`僅供對同來源、已驗證SHA的資料重新封裝；修改配置配方時應使用預設完整重跑。

索引：[frontier-balance-v612.json](frontier-balance-v612.json)，列出來源指紋、配方指紋及十份原始資料的SHA256。失敗、死亡、寵物死亡與藥水消耗均保留。V6.1舊報告改標為歷史檔，不再聲稱代表目前怪物數值。
