# V5.0.6 技能清單與征途任務

## 自訂施放清單

在「角色 → 技能配置」選擇已學的主動技能，按「新增技能」加入末端；用上下箭頭決定優先程度，按「移除」取消自動施放。移除不會遺忘技能。清單可為空，普通攻擊照常進行。被動技能仍永久生效，不需排入清單。

新學的技能不自動加入；學習轉生替代主攻時，只有原主攻已在清單中才會原位換成新主攻。冷卻、SP或武器不符會向下嘗試，零CD技能排最前仍可能占用施放機會，沒有自動最大化排序。戰鬥技能列只顯示清單中的招式，技能學習區保留所有可學技能。

舊存檔依原本啟用的順序遷移，清除未學技能、停用項目及重複護盾；同類護盾保留原優先順序中最前的一個。已移除的技能不會在刷新、學技能或匯入後補回。各角色獨立存檔，線上與離線採相同清單。

## 護盾

一轉護盾CD4.8秒；具有同類護盾的二轉版本CD3.6秒。自動清單同時只能配置一個人物護盾，若要更換，先移除原護盾。手動交替使用不同護盾也共用人物護盾冷卻，避免連放繞過限制。沒有二轉護盾的職業沿用原本一轉護盾。寵物護盾仍獨立於人物技能。

## 51–99征途任務

燼火熔獄、深淵潮域、古代機城、蝕月聖域、終焉星宮五區全部改為：指定小怪雜物40個＋當區首領征途誓印5枚。接取／回報仍在靈契主城向艾琳辦理，順序與轉生條件不變。

已接取的任務直接套用新門檻，不需重接；已完成的任務維持完成。追蹤、達標提示、回報按鈕、實際扣除及線上／離線自動販賣預留數量共用40／5設定，僅保留40個任務雜物。首領證不自動出售，原有多餘材料保留。

## 驗證

新增技能清單、互斥、共用冷卻、新學技能不自動加入、空清單存檔及五區40／5精確扣除測試。並更新既有技能排序與任務測試。

護盾與清單變更會影響戰鬥，因此重新執行840場實際戰鬥驗證。為維持先前40組清怪速度差距目標，巫師「雷鳴風暴」基礎倍率由1.05微調至1.04；沒有新增職業整體傷害係數。驗證範圍與結果見 [平衡說明](balance-v50.md)與[原始樣本](balance-v50.json)。
