# 返鄉挑戰：通關曙光後的進階難度（2026-11-06）

## 本次結論

以舊十職、210 等、200 神話 SSS 裝備、契印 8、SSS 人形融合夥伴與合法首領卡建立同套配裝對照。先確認曙光混戰，再測返鄉；首次完成前不使用第四格技能。

- 八個節點 × 十職 × 兩個種子：160 場返鄉戰鬥完成，無戰敗、逾時或擊敗後未推進。
- 每場對照的曙光混戰都先擊敗首領且存活至少 60 秒。此結果僅代表兩種子的初步穩定性，不是任意配裝的保證。
- 三隻返鄉首領的 60 場戰鬥耗時全部高於同配裝曙光首領；HP、攻擊、防禦也全部高於曙光首領。
- 四種非首領的 HP、攻擊、防禦全部高於曙光高階小怪；五個節點（斥候重用於伏擊與斷後）另完成 100 場驗證。
- 流程與機制回歸 101／101 通過。人物／夥伴傷害公式、曙光怪物與正式網站均未修改。

## 配裝與方法

- 配點總額 438、單項上限 150；三個職階技能點分別 49／69／69；人物與夥伴減傷均檢查不超過 40%。
- 使用合理生存詞條：人物防具 HP%、一件減傷、對應攻擊屬性與首領卡；夥伴裝備與三格技能一併配置。六詞條均檢查合法範圍，未手填戰鬥面板或無敵狀態。
- 配裝來自既有適性測試，另抽出獨立 fixture；與原腳本的 120 種組合（十職 × 六融合 × 第四格開／關）逐欄對照一致。舊大型適性工作不因本次改動重跑。
- 曙光對照從實際首領＋三隻實際小怪開始混戰；一般生怪繼續正常補充。必須擊敗初始首領並存活至少 60 秒；未滿足者不納入返鄉平衡合格樣本。
- 同一套裝備、配點、卡片、夥伴與自動技能；每戰滿 HP／SP 起始，關閉復活與避戰，開啟自動補給。
- 種子 93217、44021；100 ms 模擬時間格，單戰上限 180 秒；沒有注入傷害、拉長敵人 HP 或直接按勝利。
- VM 與匯入模組的亂數一併固定；報告識別碼不消耗戰鬥亂數。強化前後的 60 場曙光對照結果逐欄完全相同。
