# 荒境文字戰線 V0.4

單人瀏覽器即時文字 RPG 原型，以獨立原創設定探索經典職業、怪物卡片及戰鬥寵物玩法。

## 存檔資料模型（version 2）

- `player`: 角色名稱、職業 ID、目前地圖 `location`、等級、經驗、金幣、生命、魔力、擊殺數
- `player.attributes`: `STR/AGI/VIT/INT/DEX/LUK` 六大能力與 `statPoints`
- `player.bag`: 道具 ID 陣列；`player.gear`: `weapon/armor/accessory` 已裝備道具 ID
- `player.cards`: 尚未使用的怪物卡片 ID 陣列；`player.sockets`: 三個部位的卡片 ID
- `player.pets`: 寵物個體陣列 `{id,species,nickname,level,xp,iv,hp}`
- `player.activePetId`: 當前出戰寵物 ID，`null` 表示沒有出戰
- `player.petBook`: 依物種記錄的捕捉次數

所有職業、怪物、物品、卡片及寵物定義在 `dist/catalog.js`。運算規則在 `dist/game.js`，DOM 介面獨立於資料定義。未來多人版本應將戰鬥、捕捉、掉落、交易判定移至伺服器，瀏覽器僅傳遞操作與呈現結果。

## V0.2 規則

- 玩家普攻冷卻受到 AGI 影響；主動技能 4 秒冷卻、消耗 18 MP。
- 出戰寵物每隔自身速度間隔自動攻擊（即使玩家關閉自動普攻）。
- 怪物有 35% 機率攻擊未倒下的出戰寵物。
- 怪物 HP 低於 50% 才能捕捉；消耗一顆捕捉球。可持有至多 30 隻，一次僅出戰 1 隻。
- 每個寵物有獨立成長值、等級、經驗及目前 HP。醫療站可恢復所有寵物 HP。
- 怪物卡片測試掉率 11%；裝備三個部位各有一張卡片插槽。
- 卸下或更換裝備時，原插槽中的卡片自動退回卡片庫。
- V0.1 舊角色的等級、經驗、金錢、背包和裝備會在首次讀取 V0.2 時遷移；原版 localStorage 鍵仍保留。

## V0.3：四職業與寵物之地

- 初始職業：劍士（近戰）、服事（聖光）、法師（魔法）、盜賊（高速）。職業為 RO 式設計參考，名稱與技能數值均屬原型。
- 新角色從 `petland`「寵物之地」開始，這是唯一允許使用捕捉球的地圖。`wasteland`「赤砂邊境」只允許打怪、練功、掉寶與卡片。
- 寵物之地的四種寵物：赤牙幼獸（攻擊）、星光精靈（魔法）、岩甲守護獸（防禦）、生命芽靈（輔助）。
- 攻擊型優先物理輸出；魔法型忽略大部分敵方防禦；防禦型較常吸引敵人攻擊；輔助型定期回復玩家 HP/MP。
- 舊版三種職業會自動映射：突擊兵→劍士、槍械兵→盜賊、能量師→法師。保留原本寵物及裝備資料；舊寵物仍可出戰，但只在新寵物之地捕捉新四系寵物。

## V0.4：雙向共鳴基礎

- 四初始職業 × 四寵物定位的 16 組共鳴規則集中在 `dist/resonance.js`。
- 玩家一般攻擊、職業技能、爆擊、格擋、閃避、治療，以及寵物行動都可以產生戰鬥事件。
