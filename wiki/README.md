# 靈契紀元 WIKI（獨立測試版）

此分支新增 `wiki/index.html`，不會改動 `main` 正式遊戲。

## 已有功能
- 怪物及地圖首領圖鑑（從 `dist/world-data.js` 與 `dist/map-bosses.js` 讀取）
- 卡片圖鑑與插槽（從 `dist/catalog.js` 讀取）
- 裝備詞條範圍／階級／品質與裝備名稱（從 `dist/loot.js`、`dist/progression.js` 讀取）
- 夥伴稀有度、進化與融合資料
- 機制說明、搜尋、篩選、手機版響應式版面

## 預覽方式
本檔案以 ES Modules 引用相對路徑 `../dist/*.js`。需要透過 HTTP 伺服器提供網站根目錄，不能直接點開本機 `file://` 頁面。

在完整專案的根目錄執行 `python -m http.server 8080`，然後瀏覽 `http://localhost:8080/wiki/`。

**目前尚未發布公開 WIKI URL**。這個分支只是獨立測試版，正式網站 `main` 不變。

## 資料一致性
顯示資料從正式版程式模組匯入。請注意裝備、卡片、怪物數值在套用角色屬性、升階、融合與戰鬥機制後，可能與基礎資料不同。怪物特殊攻擊、掉落率、各職業技能表及全部試煉細節仍待擴充，不應將缺省欄位當作零或不存在。

## 發布建議
可另建獨立 GitHub Pages 儲存庫，以唯讀方式定期匯出正式遊戲資料至 `wiki/data/*.json`，將 WIKI 與遊戲程式部署徹底分離；正式版本需加上版本戳、資料校驗和發布工作流程。
